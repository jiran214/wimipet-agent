# A 模块：桌面体验场

主责模块：`desktop-world`。实现版本 0.1.0，需求基线：[A0001](../PRD/A0001-desktop-world.md)。这是可独立运行的实现验证版，原生体验尚未全部验收。

## 启动与停止

环境：Python 3.11 或更新版本，附带 Tk 8.6；Windows 原生模式建议 Windows 10 2004 或更新版本。当前实测 Python 3.11.15 / Tcl/Tk 8.6.12 / Windows build 26200。无第三方运行依赖、无网络、无账号、无密钥。`pyproject.toml` 的依赖为空；当前以源码目录交付，不提供已打包安装器。复制整个 `modules/desktop-world/` 即包含运行资产。

在仓库根目录执行：

```powershell
python modules/desktop-world/run.py
```

或者在 `modules/desktop-world/` 内执行 `python run.py`。默认进入模拟桌面，自动载入三只不同颜色的本地样例。可切换右上角“Windows 原生”，也可直接启动：

```powershell
python modules/desktop-world/run.py --native
```

关闭主控制面板即停止刷新、取消回放、释放采集器和核心订阅，并销毁本进程创建的窗口。无需后台服务。模拟模式不读取个人桌面；原生模式会枚举窗口结构，只有点击“采集预览”才采集画面，不会自动截图。

若 Python 提示缺少 `tkinter`，请使用附带 Tcl/Tk 的 Python 安装。Linux 等有 Tk 的桌面环境可以尝试模拟模式，但本次未验证；原生模式只适配 Windows。全屏独占软件可能挡住界面与桌宠，请在普通桌面环境验收。

## 人工操作与预期

1. 默认显示三只样例角色，自行眨眼。点击“添加样例”可以继续增加，“移除”仅删除选中的运行时实例。也可以载入符合本模块临时协议的 `character.json`；缺文件或坏图片应报错，其余角色继续工作。
2. 选择角色并“执行动作”：`wave` 约 700ms 后从 accepted 变为 completed；`unknown` 应 rejected。循环动作直到被打断都不会报告 completed。“当前动作后排队”可排队有限动作；循环动作不会自行让位，需拖拽、停靠或释放来取消。
3. 在角色实体处按住左键拖动，角色应立即跟手；当前及排队动作应 interrupted。释放后按固定重力下落，最后停在工作区底边。动作播放过程中仍可拖拽。画布透明区不响应角色命中。
4. 选择样例窗口，依次尝试“趴在顶部”“挂在顶部”“贴右侧”。使用“窗口右移”“缩放”观察接触点跟随；悬挂中执行 wave 或 idle 应拒绝，保留悬挂。缩窄窗口时接触点偏移夹到窗口宽度内。
5. “遮挡”在模拟场切换整窗遮挡并隐藏依附角色；恢复遮挡后重新显示。最小化或关闭样例窗口应立即解除依附并下落。“新建 / 恢复样例窗口”不会恢复已解除的依附，需重新选择姿态。
6. 点击“固定事件回放”，约 8 秒依次执行依附、移动、缩放、遮挡、最小化、恢复、关闭、下落。该入口总是切回模拟模式，仅作用于体验场。点击“恢复初始场景”清空体验中的实例并恢复三只样例，不改写角色源包、用户文件或其他模块数据。
7. 采集框默认 `0,0,420,260`。点击“授权该范围”确定可采集范围，之后修改输入不会自动扩大授权。点击“采集预览”查看内存画面：模拟模式是固定桌面的合成图，原生模式是真实桌面。关闭预览释放引用，不自动保存截图。
8. 勾选“暂停采集”再采集，应直接拒绝；勾选左上排除，再采集相交范围也应拒绝。可改输入到授权区内、排除区外的小范围验证成功；除暂停外，重新授权/排除变更也会使在途结果过期。
9. “预期 / 实际 / 异常”填写实际观察，再导出 JSON。记录包括版本、环境、固定场景、步骤、状态、动作结果及最近事件；不收集窗口标题、用户包路径、密钥或个人截图。手工输入的内容由用户决定，导出前可自行检查。

原生附加操作：角色在真实桌面显示，控制面板内不再重复显示角色。可以直接拖动桌宠，拖动 / 缩放本模块自带的“原生测试窗口”，或从窗口下拉框选择其他现有窗口依附。控制按钮只移动、缩放、最小化和关闭本模块自己的测试窗口；不会操作其他软件。操作其他应用的窗口请手工完成。

请人工检查：动作连续性和切换跳动、拖拽跟手、依附移动是否抖动、透明区域能否点击到下方软件、多个桌宠重叠时是否符合后创建角色在上的规则、角色是否抢焦点、最小化/退出是否残留。原生整窗遮挡目前只识别被单个更高层窗口完整覆盖的情况，部分遮挡不会逐像素裁剪。

## 模拟、真实与未接通项

| 能力 | 模拟模式 | Windows 原生模式 |
| --- | --- | --- |
| 身体、动画、指令结果 | 共用正式核心 | 同一核心 |
| 窗口移动 / 缩放 / 最小化 / 关闭 | 固定事件 | EnumWindows 等 API，每 100ms 轮询 |
| 当前窗口切换 | 无真实系统事件 | 前台标记变化；不是系统事件钩子 |
| 任务栏停靠 | 固定 y=600 | 主屏工作区底边，工作区变化会更新 |
| 角色显示 / 透明穿透 | Canvas 透明像素命中测试 | 透明 Tk 窗口 + 按像素 HRGN + 不抢焦点样式 |
| 遮挡 | 明确控制整窗遮挡 | 单个上层窗口完全覆盖目标才隐藏依附角色 |
| 截图 | 合成 PNG，无个人桌面数据 | GDI 范围截图，自身窗口临时隐藏并等待 DWM 刷新 |
| 图标结构 | 不提供 | 明确不支持，未接通 |
| AI / 生图 / 聊天 | 不提供 | 不提供，本模块不调用模型 |

没有“真实模型配置”项：本模块职责内没有模型调用；无需提供任何 AI 凭据。真实模型质量验证不适用于 A，本地自绘样例不代表 B 的生图质量或 C 的陪伴质量。

原生多屏坐标按虚拟桌面物理像素实现，但角色当前约束到主屏工作区；多屏任务栏、混合 DPI、负坐标桌面的视觉效果、特殊/全屏/权限隔离窗口仍待平台验收。截图会短暂隐藏自身界面；不保证其他采集软件也排除桌宠。对 D 窗口的排除与宿主嵌入能力尚待联调。

## 自动检查

```powershell
python -m unittest discover -s modules/desktop-world/tests -v
python modules/desktop-world/tests/gui_smoke.py
python modules/desktop-world/tests/gui_smoke.py --win32
```

第一条只测试规则，不要求 GUI、模型、网络或真实截图；后两条需要可创建 Tk 窗口的桌面会话。`--win32` 读取真实窗口结构并检查隐藏原生窗口的命中区域，不采集个人桌面截图，不向其他应用注入输入。程序化 GUI 检查不等于人工观感验收。

规则与协作约定见[接口与身体规则](接口与身体规则.md)，本次实际结果和待验收项见[验证记录](验证记录.md)。
