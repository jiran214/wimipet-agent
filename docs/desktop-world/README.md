# A 模块：桌面体验场 0.2.0

主责 desktop-world；需求：[A0001](../PRD/A0001-desktop-world.md)、[A0002 迁移](../PRD/A0002-统一协议与异步观察迁移.md)。公开边界只遵循根 AGENTS.md 的 `wimipet/1`，不再公开旧 A-display/1 / A-world/1 草案。原生桌面目标仍有未验收项。

## 启动与环境

Python 3.11+，附带 Tk 8.6。Windows 原生模式建议 Windows 10 2004+；本次实测 Windows build 26200、Python 3.11.15、Tcl/Tk 8.6.12。无第三方运行依赖、账号、网络或密钥。本模块没有模型调用，不需要填写 AI 凭据；固定样例不代表真实生图或陪伴质量。

在仓库根目录运行：

```powershell
python modules/desktop-world/run.py
```

也可在模块目录运行 `python run.py`。默认模拟桌面，载入三份已迁移的 wimipet/1 自绘包；演示和正式入口共用 World / DesktopWorldAPI。右上角可切换 Windows 原生，或执行 `python modules/desktop-world/run.py --native`。

关闭主面板正常退出，取消计时器、请求和回放，销毁自有角色/预览/测试窗口。复制整个模块目录即可离线体验，自带所有资源。当前提供源码入口，未提供安装器。缺 Tk 时请使用附带 Tcl/Tk 的 Python 安装。全屏独占软件可能挡住界面，不在其他应用画面上盲目操作。

## 操作与预期

1. 初始三只自绘角色会眨眼。添加样例、移除、载入统一 JSON 角色包；一个包可创建多个实例。载入失败不影响其他实例，也不改写源文件。
2. 右侧控制栏可滚动。点击“加载共同 v1 包（仅 idle / wave）”，看到协调层共同包；再次点击得到另一个 instanceId。动作下拉框来自实际加载包。共同包的 idle 为 160px，wave 为 64px，画风/尺寸差异是共同素材本身的特性，不用于视觉质量验收。
3. 选择 wave 执行，约 700ms 后显示 completed；unknown 明确 rejected。勾选排队可观察 queued→accepted→completed。循环动作不会自行完成；拖拽、释放、停靠或取消会终结请求。拖动实体可在播放中即时打断，释放后下落到工作区底边。
4. 自绘姿态样例可以趴/挂/贴窗口。移动/缩放样例窗口时跟随，遮挡切换隐藏/恢复；最小化或关闭后解除依附下落。**共同 v1 包没有姿态资产，挂/贴/趴请求必须显示 unsupported-capability，不伪造姿态。**
5. 采集框是授权范围，修改数值后点击“授权该范围”。desktop 只截授权矩形；active-window 在请求时解析实际活动窗口，整个窗口须在授权范围内，否则拒绝，不静默裁切。模拟环境的活动窗口是固定样例。原生控制面板本身不作为可观察活动窗口；焦点在自身面板、没有可支持的外部活动窗口时明确 unavailable。
6. 选择范围、暂停、排除区域均由 A 确认递增 policyRevision 后生效。勾选暂停再采集应拒绝；排除区域与范围相交时整次拒绝，不能先采集再涂黑。授权或策略变化使在途结果过期，暂停后恢复也不接纳旧画面。
7. 勾选“模拟慢采集 1.5 秒”，点击采集后继续拖动角色；也可点击取消，或采集中勾选暂停。身体继续刷新，取消/旧策略画面不会出现预览。原生模式忽略模拟延迟，GDI 和 PNG 处理运行于后台线程。
8. 成功后出现内存预览，标明 simulation/native、实际范围及策略版本。默认不落盘；关闭预览、重置或退出释放引用。模拟画面只画固定环境，不读取个人桌面。
9. 滚到控制栏下方，使用“固定事件回放”观察约 8 秒窗口事件。恢复初始场景产生新 sessionId，取消旧任务、清理体验实例/预览并恢复三只样例，不删除用户包或其他资产。
10. 填写预期/实际/异常，导出 JSON 复现记录，包含模块版本、场景、会话、步骤、公开事件和位置；不自动收集截图、密钥、窗口标题或包路径。手填文字由用户控制。

原生模式可直接拖动真实桌面角色；窗口下拉框提供真实枚举对象。面板移动/缩放/最小化/关闭按钮只操作本模块的原生测试窗口，不代用户操作其他软件。真实外部窗口请手工移动验证。

## 真实 / 模拟能力与缺口

| 能力 | 当前状态 |
| --- | --- |
| 身体、动作、能力校验 | 两种模式共享真实核心，统一包实际解码 |
| 模拟窗口 / 合成截图 | 固定样例，不当成原生验收 |
| 原生窗口 / 工作区 | Win32 100ms 轮询，主屏工作区底边停靠，非事件钩子 |
| 透明角色 / 焦点 | Tk 透明顶层 + HRGN 像素区域 + NOACTIVATE；隐藏窗口检查已做，真实穿透/观感待验收 |
| 观察 | 后台采集，主线程确认策略和交付结果；超时/取消/重置丢弃迟到结果 |
| 自身排除 | 自有宿主逐个登记 targetId，平台核验 WDA_EXCLUDEFROMCAPTURE；不能核验则拒绝原生截图，不再在 UI 线程临时隐藏后同步截图 |
| 跨进程气泡排除 | 提供平台 resolver 与 targetId 登记入口；未连接实际 D 宿主，未宣称实测通过 |
| 图标 / 遮挡 / 多屏 | 图标未接通；只识别单个上层窗口完全覆盖；多屏/混合 DPI、部分遮挡、特殊权限窗口待验收 |

原生 API 排除属性核验不能替代真实像素效果检查。尚未完成真实截图、自身排除、桌面拖拽/层级/穿透的完整人工验收。模块不会调用其他模块私有代码，也不包含聊天、人格或模型策略。

## 检查与消费者入口

仓库根目录：

```powershell
python -m unittest discover -s modules/desktop-world/tests -v
python modules/desktop-world/tests/gui_smoke.py --win32
python modules/desktop-world/tests/probe_v1.py docs/contracts/fixtures/v1/character-package.json
```

规则测试无需 Tk、模型或个人截图。GUI 检查要求可创建 Tk 窗口；Win32 检查只读结构和隐藏窗口/合成内存位图，不采集个人桌面像素。探针使用真实 A 包加载器，输出能力、同包实例、wave 终态和规范位置；它不是 B 真导出或 A/B/C/D 全链路证明。
