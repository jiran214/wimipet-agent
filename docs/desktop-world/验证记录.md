- 当前 Windows 会话，系统版本字符串 `Windows-10-10.0.26200-SP0`；Python 3.11.15、Tcl/Tk 8.6.12，64 位。

- 执行 `python modules/desktop-world/run.py` 成功创建标题为“A · 桌面体验场 0.1.0”的窗口，进程持续运行且无启动异常。检查后已结束该开发进程；未留下常驻体验场进程。

## 自动规则检查

执行：

```powershell
python -m unittest discover -s modules/desktop-world/tests -v
```

结果：18 项通过，涵盖：

- 13 个实例的集合化载入与单独移除；三份随包固定角色资产。
- 未知动作拒绝；悬挂中挥手及错误接触类型拒绝；有限动作 700ms 时才完成。
- 动作队列、优先级、拖拽中止当前和排队动作；释放后的下落与停靠。
- 宿主播放故障产生 failed 而非 completed，取消后续队列；旧请求故障不能终结新动作。
- 序列帧接触点、窗口移动 / 缩放、移出工作区、遮挡 / 恢复、最小化 / 关闭。
- 工作区变化后脚底停靠；快照 / 订阅隔离；取消订阅及幂等释放。
- 坏协议、缺失资产、越界资产路径、非法接触点拒绝。
- 范围越界、暂停、排除相交时不调用采集器；策略变化后在途结果过期并丢弃图像；采集错误与释放回收请求。

另外执行 `python -m compileall -q modules/desktop-world/src`，无编译错误；执行 `git diff --check`，无空白错误。

## 程序化 GUI / Windows 集成检查

执行：

```powershell
python modules/desktop-world/tests/gui_smoke.py --win32
```

结果通过。这是本模块自身 Tk 控件 / 回调驱动的集成检查，不是人工点击或视觉验收。

- 创建三只角色，Tk 实际解码 63 个 PNG 帧；共用产品 World 核心。
- 调用体验入口执行动作；画布命中及拖动回调中止动作，释放后下落。
- 依附 / 窗口移动 / 最小化；暂停采集拒绝；合成截图创建真实 Tk 预览窗口；重置释放预览。
- 完整推进固定模拟回放，验证结束后没有失效依附或样例窗口引用，角色停靠。
- 注入单只角色的宿主资产引用损坏，输出关联 failed 并隔离该实例，其余两只继续渲染，重置恢复三只。
- 调用真实 Win32 枚举、工作区 API；创建隐藏的真实 HWND 并设置 HRGN，检查透明角点不在区域、身体像素在区域；NOACTIVATE 样式已设置。
- GDI 截图编码共用路径从**合成白色内存 DC**读取像素，输出 PNG 再经 Tk 解码，检查白色像素一致。没有从个人桌面读取画面。
- 原生宿主创建并释放三个隐藏 overlay，未将其显示到用户桌面。
- 关闭后检查 World、CaptureGate、图片缓存、overlay 和 Tk 窗口清理，after 已取消。

## 人工体验状态

尝试使用 computer-use 工具选择并激活体验场。首次激活返回 `failed to activate captured window`；刷新窗口选择后仍返回当前全屏应用的画面，而非体验场。为避免向非目标应用发送输入，没有继续点击或拖拽，没有操控或关闭用户的全屏应用，也未将该画面保存为项目资产。

因此以下均为**未完成人工确认**，不能据程序化集成检查声称通过：

- 控制面板实际布局、文字可读性、不同屏幕尺寸下的裁切。
- 真实跟手程度、序列帧连续性、接触点抖动、窗口层级与焦点行为。
- 对下方真实应用的透明区域点击穿透、角色重叠交互。
- 真实窗口移动 / 缩放 / 最小化 / 关闭的全链路观感，以及整窗遮挡显示效果。
- 真实桌面截图内容、自身排除效果、暂停后人工操作反馈；当前只验证策略与合成数据路径。
- 普通桌面退出后实际可见窗口残留情况；已做程序化资源清理检查。
- 多屏、负坐标、混合 DPI、特殊权限窗口、全屏应用与性能预算。

人工可按[启动与操作说明](README.md)逐项执行，在面板导出带版本、步骤、预期与实际观察的 JSON。人工发现问题后，应补记环境与复现步骤；不要将这一节直接改成“通过”。

## 模型效果评审与需求缺口

本模块没有 AI 调用，未进行模型效果评审。样例 PNG 为项目固定自绘素材，不证明真实生图质量或互动质量。

尚未接通桌面图标结构、精确部分遮挡、跨进程 UI 排除、正式 B/C/D 协议、原生宿主嵌入。当前 Windows 系统事件是 100ms 轮询，不是事件钩子。身体物理、动作格式和性能阈值是本次实现验证选择，仍待用户体验和平台实测确认。A0001 首版验收保持开放，不声明全部完成。
