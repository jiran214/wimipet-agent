## 自动规则 / 公开 facade

```powershell
python -m unittest discover -s modules/desktop-world/tests -v
```

当前 **35 项通过**：原身体/门控规则 18 项，公开 v1 迁移 17 项。包括：

- 统一包原始字节校验和实际 PNG 解码、同包多 instanceId、原子替换失败保留旧 revision。
- 缺少真实姿态时拒绝且不改变身体；不要求 idle 覆盖挂/贴/趴；动作清单来自实际加载包。
- accepted / queued / completed / rejected / interrupted / failed 全生命周期；循环取消、排队取消、渲染故障、单调截止时间、终态不复活。
- 重复不执行、不同 payload conflict、有效去重记录容量满拒绝、旧请求和旧会话 stale；未知版本与必需能力结构化拒绝。
- Position 是图像左上角而非接触世界点，含 anchor、负显示器原点、scaleFactor；事件 atMs 为 epoch，sourceSeq 单调。
- PNG CRC 损坏、声明尺寸错误、小数时长、接触点越界、root-motion、超长人设、动作重名/混合画布拒绝；宿主解码异常不泄露私有信息。
- 使用线程 Event 屏障而非 sleep：采集器阻塞等待期间主线程仍完成 wave；暂停再恢复/策略变化后旧画面丢弃。
- 采集成功、引用读取/释放、坏 PNG 不生成引用、取消、超时、失败、重置后迟到、范围越界、排除相交、活动窗口范围解析和 cooldown。
- targetId 未登记、排除未就绪或采集中失效时 unavailable，不输出声称已排除的画面。

另执行 `python -m compileall -q modules/desktop-world/src` 无错误。暂未为原生延迟/帧率设置通过阈值。

## 本轮实际界面操作（模拟模式）

使用 computer-use 读取真实目标窗口并逐步点击 / 拖动，未保存个人截图或将截图纳入资产：

1. 初始三只样例显示；控制栏可滚动，下方重置/反馈入口可见。
2. 点击“加载共同 v1 包”，第四实例实际显示共同素材。执行 wave 时可见其帧变化，结束恢复 idle；共同包动作尺寸/画风差异如实呈现，没有冒充统一视觉质量。
3. 点击“挂在顶部”，面板显示 unsupported-capability，角色仍 standing，无失效依附。
4. 勾选模拟慢采集、提交后看到异步受理状态；拖动第四实例到高处，实际位置改变并下落，合成采集预览独立出现。此操作不是延迟性能基准，线程屏障测试另证主循环不等待采集。
5. 勾选暂停，面板显示 A 已确认 policyRevision=2；再次采集明确 unavailable / 观察已暂停。
6. 滚到下方恢复初始场景，sessionId 改变，第四实例和预览移除，三只样例恢复；随后正常关闭主面板。

这些是工具操作的实际 GUI 验证，不等于用户主观陪伴/观感评审。未在本轮进行原生桌面角色显示、真实截图、对其他软件的穿透点击或跨进程气泡排除操作。
