# A 公开入口与身体规则（0.2.0）

唯一跨模块规范是根 [AGENTS.md](../../AGENTS.md) 的 `wimipet/1`。本文件仅说明 A 的实现映射、调用方法、运行限制；不另立候选契约。需求主责为 [A0002](../PRD/A0002-统一协议与异步观察迁移.md)。0.1 的 A-display/1 / A-world/1 不再用于公开接入，历史版本可从提交 3c08b1a 查阅。

## 入口和线程

导入 `desktop_world.api.DesktopWorldAPI`。将 `modules/desktop-world/src` 加入 Python 路径即可，无第三方运行依赖。

- `handshake()`：`{protocol,module,implementationVersion,capabilities,limits,sessionId,sourceInstanceId}`，未注入采集器时异步采集能力为 false，图标/精确遮挡始终如实声明 false。
- `request(envelope)`：统一同步受理入口，返回 JSON 响应；采集只返回受理回执，最终事件异步交付。`loadCharacter(envelope)` / `applyObservationPolicy(envelope)` 为同一入口的便利别名，信封仍须带相应 type。
- `subscribe(listener)`：返回可重复退订的函数，返回前不调用 listener；后续在 `poll()` / `tick()` 中交付深拷贝事件，订阅异常不阻断身体。
- `tick(deltaMs)`：推进单调身体时钟并排空事件；返回本次事件数组。`poll()` 只处理截止时间和采集完成队列。事件可经返回值或订阅消费，选择其中一种避免重复显示。
- `getPositions()`：原子读取当前 sessionId 及 Position 数组。`readResource(contentRef)` 获取 PNG 字节供装配资源桥读取，`releaseResource(contentRef)` 释放；不能把任意路径或浏览器 blob 当成此引用。
- `authorize(Rect)`：宿主明确注入用户授权范围；策略不能自行扩大权限。`reset(world?)` 产生新 sessionId，先终结旧请求再释放旧状态和画面，重置观察为 paused；`close()` 终结并释放，重复关闭安全。

facade、World、Tk 和订阅回调必须在**创建 facade 的宿主线程**执行。后台线程只采集/校验 PNG 并向完成队列交付，不触碰 World、Tk 或消费者。装配若使用 asyncio/IPC，需要将调用转回该线程并周期性 pump，不直接跨线程调用。本模块不提供 HTTP 服务，也未替装配决定进程架构。

接入 Windows 宿主时，须在创建任何 Tk/宿主窗口前调用 `WindowsDesktop.enable_dpi()`；独立 run.py 和 GUI 检查已这样执行，不能将未设 DPI 感知的外部宿主坐标冒充物理像素。

最小真实包消费者例子（仓库根目录）：

```python
import json, sys, time, uuid
from pathlib import Path
sys.path.insert(0, str(Path("modules/desktop-world/src").resolve()))
from desktop_world.api import DesktopWorldAPI
api = DesktopWorldAPI()
def send(kind, payload):
    return api.request({"protocol": "wimipet/1", "sessionId": api.session_id,
        "requestId": str(uuid.uuid4()), "expiresAtMs": time.time_ns() // 1_000_000 + 60000,
        "type": kind, "payload": payload})
package = json.loads(Path("docs/contracts/fixtures/v1/character-package.json").read_text(encoding="utf-8"))
loaded = send("LoadCharacter", {"instanceId": "instance-one", "package": package})
print(loaded)
print(send("ActionCommand", {"instanceId": "instance-one", "actionId": "wave", "enqueue": False}))
print(api.tick(700))
api.close()
```

`tick(700)` 是本地受控身体时钟，不会把墙钟向前推 700ms；真实截止时间仍使用接收时计算的单调截止时间。测试可注入 epoch_ms / monotonic，不能将单调秒当成 UTC。回放为显式模拟场景，不代表真实耗时指标。

## 信封、错误与去重

请求必需字段为根规范的 protocol/sessionId/requestId/expiresAtMs/type/payload。事件包含 eventId、source=A、sourceInstanceId、sourceSeq、atMs 和原 requestId；时间为 epoch 整数毫秒，sourceSeq 在生产方实例内单调。自动位置/结构事件使用自己的关联标识。重建 facade 会换 sourceInstanceId；原地 reset 保持生产方序号单调但换 sessionId。

基础错误返回 `type: Error` 和 `{error:{code,message,retryable}}`，不泄露原生句柄、私有提供方响应。未知主版本、未知必需能力、实例不存在、保留 instanceId=all、非法字段、冲突和过期均明确处理。

以 sessionId/requestId 去重，指纹为 type/payload/必需能力声明的 SHA-256；相同请求返回已受理/最新动作或采集结果，不再执行。同 ID 不同内容 conflict。接收时将 expiresAtMs 与 epoch 的差换算到单调截止时间，之后不受系统时间跳变影响；同 ID 重试不能延长原截止时间。至少保留至原 expiresAtMs，1024 个有效记录满时拒绝新请求，不提前逐出。结束后过期记录可回收；reset 换会话后旧信封 stale。

## 已实现请求 type

| type | payload / 结果 |
| --- | --- |
| LoadCharacter | `{instanceId,package}` → CharacterLoaded，含 packageId/revision/supportedActions/supportedPostures |
| RemoveCharacter | `{instanceId}` → CharacterRemoved，先终结该实例请求 |
| ActionCommand | `{instanceId,actionId,enqueue}` → ActionResult；后续终态通过同请求事件 |
| AttachCharacter | `{instanceId,surfaceId,posture}`，本模块附加操作，缺实际姿态 unsupported-capability |
| ApplyObservationPolicy | 规范 ObservationPolicy → ObservationPolicyApplied，返回实际已应用字段 |
| CaptureRequest | `{policyRevision,sceneId,scope}` → CaptureReceipt，后续 CaptureResult/CaptureError |
| RegisterHostTarget / UnregisterHostTarget | `{targetId}`；外部没有原生句柄，排除无法核验则 unavailable |
| CancelRequest | `{requestId}`，指向原请求；动作中止或采集取消，不伪造完成 |
| ReleaseResource | `{contentRef}`，释放画面引用 |

附加操作不是新的公共协议版本；未知 type 明确 unsupported-capability。宿主指针拖动通过内部 World 的 drag_start/drag_move/drag_end 驱动同一身体实现，facade 会输出规范位置和关联动作打断。

## 角色包加载与能力

包结构、尺寸、数量、资源、时长、接触类型和 motion 均按根规范校验。UTF-8 包不超 32MiB、内嵌 PNG 每项不超 2MiB、资源 1–256、动作 1–64、每动作 1–128 帧、画布不超 512×512、时长 16–10000 整数、优先级 0–100、同动作画布一致。拒绝 root-motion，不丢弃位移来凑原地动作。人设最多 20000 Unicode 码点，不静默截断。

默认解码器验证 PNG 块 CRC、压缩流、实际滤波扫描线（含 Adam7）、尺寸及完整性；Tk 宿主还用 PhotoImage 实际解码每个资源。所有校验/解码完成后才原子替换实例，失败保持旧版本和身体。数据留在内存，不写临时角色文件，不读其他模块目录。Package.load 默认仅接受统一包，历史磁盘包只能显式 `allow_legacy=True`，不在 facade 中自动转接。

idle 只需覆盖 standing/falling/dragging、feet、loop=true。supportedActions 来自实际包，allowedStates 过滤接触类型永不可能支持的状态。lying/clinging/hanging 要有匹配 contactKind、允许状态且能维持该姿态的循环资产才声明 supportedPostures。缺少时在任何身体改变前拒绝，不假造素材或让 feet idle 冒充挂姿。

本模块自带共同包副本 `fixtures/v1/character-package.json`，来源共享规范提交 a24c406；测试与 `docs/contracts/fixtures/v1/character-package.json` 比较原始字节，不修改双方文件。本次 A 是实际消费者，但协调层共同样例不是 B 新实现真实导出，后续仍需 B→A 导出往返。

## 动作生命周期和身体

保留 queued/accepted/completed/rejected/interrupted/failed。受理不等于完成；有限动作全部时长结束才 completed，循环永不自行完成。拖拽/取消/窗口失效是 interrupted，宿主播放故障通过 World.fail_action 产生 failed。超时也明确终结（当前接受动作 failed/timeout，排队中止并带 timeout 原因），终态不复活。排队容量 8，开始前重新验证，取消当前动作可启动下一条合法排队动作；拖拽和姿态切换会取消旧队列。

以下仍是首轮实现验证规则，不升级为产品确认算法：重力 1000px/s²，无横向速度，物理子步最多 16ms；非依附角色夹在主屏工作区，底边停靠。窗口顶边可趴/挂、右侧可贴，窗口缩窄夹接触偏移；最小化/关闭解除依附下落，恢复不自动重依附；完全遮挡隐藏但继续动画。无角色间碰撞，后创建的实例在上。原生仅近似识别被单个更高层窗口完全覆盖，部分/组合遮挡不精确处理。

内部 World 保留接触世界坐标；公开 Position **x/y 是图像左上角**，anchor 是当前帧内接触点。width/height 是当前图像物理尺寸。原生 MonitorFromPoint / GetMonitorInfo / [GetScaleFactorForMonitor](https://learn.microsoft.com/en-us/windows/win32/api/shellscalingapi/nf-shellscalingapi-getscalefactorformonitor) 提供目标显示器 originX/originY/displayId/scaleFactor；模拟为指定模拟显示器（默认 0,0 / 1）。即使身体未动，宿主缩放变化也触发 Position；查询暂时失败时发 PositionError，不冻结身体或伪造缩放。D 的 CSS 坐标转换属于装配，不能直接将接触点当图像位置。真实多屏视觉效果仍待验收。

## 非阻塞观察与宿主排除

ApplyObservationPolicy 完整校验递增 policyRevision、paused、scope、cooldownMs=0–300000、excludedRegions 后同步确认。默认 paused，只有实际确认后 UI 才显示生效。策略/授权/宿主登记变化会终结旧采集并丢弃旧资源；暂停再恢复仍不能接受旧 revision。active-window 在接收时由注入的 resolve_scope 解析真实范围；整个范围须在授权矩形内，排除相交整次拒绝，不扩大权限也不先采集后涂黑。

构造注入 `capture_backend(rect,cancel_event)`、`resolve_scope(scope)`、`target_ready(targetId)`。最多两个尚存活的工作线程，不因逻辑取消便无限创建新线程。后台执行采集、PNG 完整性和实际尺寸校验，主线程 poll 再验证会话、策略世代、deadline 和排除就绪状态后发布 CaptureResult。sceneId 原样关联，由 C 在分析/发布前再核对其当前场景。失败、取消、超时、过期分别有明确结构化原因。

画面只留内存，以不透明 A-image 引用供资源桥读取，容量 32MiB。释放/策略改变/reset/close 清理；UI 解码成预览后立即释放桥引用。不会默认截图、保存个人画面或调用模型。

WindowsDesktop.register_host(targetId,widget) 在平台适配器内保存句柄、设置并核验 WDA_EXCLUDEFROMCAPTURE。外部宿主通过平台内部 register_external_host(targetId,resolver) 解析句柄；外部拥有者需先设置系统排除，facade 仅接收 opaque targetId。所有自身角色、面板、预览、测试窗口均登记；登记失败保留“不就绪”目标并拒绝采集，不静默绕过。跨进程 D 宿主未联调，不能声称已排除其气泡。

不再在 Tk 主循环隐藏窗口后同步截图。后台 GDI 使用已核验的排除属性；该属性不是严格内容保护承诺，实际像素排除仍须人工验收。参见 Microsoft [SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)、[GetDIBits](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-getdibits)、[SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)。

取消信号是线程内 Event，不跨进程传递；公开取消只使用请求 ID。原生 GDI 正在执行的系统调用不能被 Python 强制终止，逻辑取消立即生效，完成后 finally 释放 GDI；迟到结果不交付。工作线程为 daemon，不使退出等待外部失控采集器，宿主自定义采集器应协作检查取消信号。本轮测试证明协作采集器退出，无真实 GDI 卡顿/延迟预算保证。

## 集成门槛

共同包 A 实际解码、动作与位置协议自测已实施，Tk 界面实际操作单列记录。B 真导出→A、C→A→C 状态消费、A→D 坐标与缩放、D 跨进程排除、装配 IPC 与退出顺序仍需真实消费者验证。没有跨模块实现导入、私有状态共享或第二份消息 List。
