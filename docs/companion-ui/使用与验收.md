# D 模块：界面体验台

本模块实现位于 `modules/companion-ui/`，版本 0.1.0。只呈现获准消息和接收用户操作，不调用模型、不采集桌面、不实现角色制作。核心界面与演示使用同一份 `src/view.js`、`src/model.js`；演示注入模块自带 `demo/host.js`，不需要 A/B/C 在线。

## 启动与停止

环境：Windows PowerShell、Node.js 22 或更新版本、现代 Chromium 浏览器。无运行时第三方依赖，不需要 npm install、不需要密钥。

在仓库目录执行：

```powershell
npm start --prefix modules/companion-ui
```

打开 `http://127.0.0.1:4317`。服务器仅监听本机。端口占用时：

```powershell
$env:PORT = '4318'
npm start --prefix modules/companion-ui
```

页面的“停止体验”卸载界面、取消样例播放并释放体验图片；“恢复初始场景”可继续。关闭页面解除订阅和计时器。终端 Ctrl+C 关闭 HTTP 服务。所有数据只存在本次页面内存中，刷新即恢复；没有读写用户资产、账户、截图或其他模块私有目录。

## 可重复操作

| 操作 | 预期现象 |
| --- | --- |
| 点击播放、暂停、速度，或逐次点击下一步 | 固定 7 步消息按顺序推进，三角色各自位于舞台不同位置；暂停后不推进 |
| 连续下一步，制造密集消息 | 最多展示三个短气泡，拥挤时省略气泡，完整历史仍可回看 |
| 点击气泡或展开对话 | 气泡消失，面板展示同一会话和原消息 ID；收起不会生成新会话 |
| 播放到长消息、边缘、角色移除 | 气泡片段可打开完整正文；离开角色的历史名字与头像占位保留；不再作为可用对象 |
| 选择林间或全体，填写文字，发送 | 回调记录含对应接收对象、请求关联 ID、输入类型；模拟宿主受理后才写入同一消息源 |
| 选择故事事件 / 条件并发送 | 消息及回调明确标出事件类型，不自行推进剧情 |
| 添加自带 PNG，或下载后拖入输入区 | 展示图片附件；发送后同一消息中显示图片；SVG 类型拒绝样例会显示提示 |
| 下次请求失败，再发送 | 保留文字、图片及对象，可重试；不会静默广播 |
| 观察设置→暂停观察 | 显示等待确认，确认前保留旧状态；模拟确认后显示“模拟…观察已暂停” |
| 下次请求失败，再恢复观察 | 明确失败，并保留已经确认的观察状态 |
| 角色制作 | 捕获打开制作工具的回调，不假装 B 已启动 |
| 空场景、恢复初始场景、从头回放 | 清空或恢复体验数据，支持重复相同输入；不涉及用户资产 |
| 展开回调记录与复现反馈 | 可填写预期/实际结果，下载含版本、场景和操作步骤的 JSON |

反馈默认记录操作类别、接收对象、文字长度、附件数量与必要错误码，不收集正文、文件名、图片内容或截图。手填反馈由用户主动提供；界面提示不要输入密钥或个人信息，并对常见 sk-/Bearer 字符串进行遮盖，这不是任意秘密检测器。下载前应确认手填内容。固定样例可按步骤回放；自定义正文和附件不导出，因此私人输入需用户自行重填，不能靠反馈文件完全还原。

## 自动检查

```powershell
npm test --prefix modules/companion-ui
```

浏览器检查为可选开发工具，运行时不依赖 Playwright。启动服务后，在模块目录执行：

```powershell
cd modules/companion-ui
npx --yes --package @playwright/cli playwright-cli -s=companion-d open http://127.0.0.1:4317 --headed
npx --yes --package @playwright/cli playwright-cli -s=companion-d run-code --filename tests/browser-check.js
npx --yes --package @playwright/cli playwright-cli -s=companion-d close
```

首次使用 CLI 需要网络下载工具及可用浏览器，必要时按 CLI 提示安装。浏览器脚本以 4317 为目标；自定义端口时需调整脚本。截图与 CLI 输出位于模块本地被忽略的 `output/playwright/`、`.playwright-cli/`，不会默认提交或收集个人截图。脚本仅操作自带假场景。

- 核心自动检查：8 项通过，覆盖消息源身份、指定角色/事件/附件、失败保留和重试、重复提交及迟到结果、原子重置与销毁隔离、边缘气泡碰撞、文件类型/大小、模拟设置确认与停止。
- 浏览器操作检查：`tests/browser-check.js` 完成，1440×1080 与 390×844 无横向溢出。通过三角色切换、指定事件、PNG 附件、DOM 拖放输入、SVG 拒绝、失败重试、设置成功/失败、历史长消息/离开角色、制作回调、空状态、停止恢复、播放暂停。最终检查期间无 console warning/error 或 pageerror。
- 反馈导出：浏览器实际下载 JSON，检查版本 0.1.0、非空步骤与手填 sk-test-secret 样例已被遮盖。仅验证该常见模式，不声明可以识别任意秘密。
- 实际操作与视觉检查：浏览器点击输入、定向发送与失败保留；查看桌面、展开面板及窄屏截图，正文完整、身份清晰，面板独立滚动。窄屏为上下排列。此项由开发代理检查，尚未进行真人主观易用性评审；系统文件管理器到浏览器的真实拖放未单独验证，脚本验证的是浏览器 DragEvent/File 数据路径。

- 真实模型效果评审：未实施。D 不直接配置模型密钥；真实模式通过宿主注入已过滤消息和真实操作回调，模型与采集配置由 C/A 管理。不得把假消息或模拟设置当成陪伴质量或真实暂停的验证。
- 未验证：真实桌宠跟随、原生窗口层级、多屏/DPI、真实附件上传/持久化、A/B/C 协议互通、真实模型质量与真人阅读打扰程度。
