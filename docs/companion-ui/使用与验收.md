# D 界面体验台：启动与验证

模块版本 0.2.0，公开边界按根 `wimipet/1` 实现 D 消费/请求子集。界面、facade 与演示使用相同核心；demo 只注入假消息源、位置、设置确认和资源桥，不调用模型、不采集桌面、不启动 B 制作工具。

## 环境与启动

Windows PowerShell、Node.js ≥22、现代 Chromium 浏览器；零运行时第三方依赖，无需 npm install、模型账号或密钥。

在仓库根目录执行：

```powershell
npm start --prefix modules/companion-ui
```

打开终端打印的本机 URL，默认 `http://127.0.0.1:4317`。端口占用会明确报错；可设置 `$env:PORT='0'` 使用临时端口，或设置明确的其他端口。页面显示版本、模拟模式与会话 ID 尾部，重置产生全新 sessionId。关闭服务使用启动终端 Ctrl+C；只停止自己创建的进程。

页面“停止体验”卸载 UI、取消演示计时器和请求并清理会话资源；“恢复初始场景”可重新开始。关闭页面解除订阅和定时器。场景只存在内存，没有用户资产读写、后台截图或跨模块私有目录访问。

普通播放使用 live epoch 时钟；“从头回放”明确显示回放时钟，每步逻辑推进 2400ms，暂停时展示时钟停止。速度控制的是实际步进间隔，不重写已有消息 atMs。请求超时仍使用独立单调时间，不随回放暂停。

## 人工体验步骤

| 操作 | 预期现象 |
| --- | --- |
| 播放/暂停/调速/下一步 | 固定 7 步，包含共同包的两个实例“苔苔·一/二”和第三角色秋实，角色位置独立 |
| 展开气泡、收起面板 | 同一 messageId/seq/atMs，面板展开时没有气泡；历史不重新变成新消息 |
| 持续下一步 | 长消息可完整回看，边缘位置仍有界；移除苔苔·二后保留历史身份 |
| 选择一个实例或全体发送 | 回调显示实际 instanceId/all；正文/对象不会被刷新或日志改写 |
| 切换故事事件 / 条件 | 请求 kind 为 story-event，不在 D 推进剧情 |
| 添加自带 PNG，清空正文发送 | 单图无正文可以受理，历史显示图片，没有补假台词 |
| 下载 PNG 后拖入，或选取 JPEG | 本地资源桥验证输入与预览；请求只含不透明 contentRef，不含 previewUrl |
| 拖入两张图、SVG/WebP/GIF 或超 2MiB | 明确拒绝；多图全部不添加，不静默丢一部分；正文限制 4000 Unicode 码点 |
| 下次请求失败→发送 | 显示结构化错误码，保留草稿、对象和附件，支持明确重试 |
| 下次请求等待→发送→取消提交 | 显示 cancelled，草稿保留；取消不等于上游模型停止计费 |
| 下次请求等待→发送并等待 10 秒 | 显示 timeout，草稿保留；真实上游有无受理仍须看权威处理事实 |
| 观察设置→暂停、恢复、选择 10秒/60秒 | 提交具体 cooldownMs、policyRevision、scope 和排除范围；确认前保留旧策略 |
| 下次请求失败→操作设置 | 显示失败，已确认的暂停/频率/策略版本保持不变 |
| 角色制作 | 捕获入口回调，模拟模式不会声称 B 已启动 |
| 空场景、恢复、从头回放 | 清理的只有体验数据与草稿；新 session 隔离旧成功/失败响应 |
| 展开回调与复现反馈、下载 | JSON 含协议、版本、场景、会话、步骤及必要错误，便于复现 |

反馈只自动收集操作类别、请求 ID、接收对象、码点数、附件数量和错误码，不收集正文、图片/文件名或个人截图。手填反馈请勿含秘密；常见 sk-/Bearer 模式会遮盖，但不是任意秘密识别器。固定样例可回放，私人正文/附件不导出，因此需用户自行重填才能还原私人输入。

## 检查命令

在仓库根目录执行核心测试：

```powershell
npm test --prefix modules/companion-ui
```

浏览器检查是开发工具，需要网络下载 CLI 和可用 Chromium；运行时无需 Playwright。在模块目录执行（URL 替换为本次服务实际端口）：

```powershell
cd modules/companion-ui
npx --yes --package @playwright/cli playwright-cli -s=companion-d-v1 open http://127.0.0.1:4317 --headed
npx --yes --package @playwright/cli playwright-cli -s=companion-d-v1 run-code --filename tests/browser-check.js
npx --yes --package @playwright/cli playwright-cli -s=companion-d-v1 close
```

脚本读取当前页面 URL，不硬编码端口；使用清晰定位器、状态等待和受控浏览器时钟，不以固定 sleep 猜测任务完成。截图/日志仅写模块内被忽略的 `output/playwright/`、`.playwright-cli/`，只含自带假数据。共同样例校验在 Node 测试中比较共享原件与模块副本 SHA-256；生产环境 UI 不访问根样例或其他模块目录。
