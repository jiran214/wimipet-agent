# D 公开接入：wimipet/1

唯一规范为 [根 AGENTS.md](../../AGENTS.md) 的统一契约。本文件说明 D 0.2.0 的函数绑定与注入方式，不新增第二套跨模块数据规范。D0002 迁移目标见 [需求](../PRD/D0002-wimipet-v1宿主边界迁移.md)。未执行真实 C/A/装配联调，以下签名供装配接入；使用模拟提供方跑通不等于跨模块通过。

## 公开入口与握手

```javascript
import { createCompanionHost, mountCompanion, declaration } from './modules/companion-ui/src/index.js';
const host = createCompanionHost({ conversation, presentation, transport, resources });
const ui = mountCompanion(container, host); // 页面加载 src/style.css
// 关闭顺序：先移除界面，再结束 facade，最后由装配关闭提供方、释放会话。
ui.dispose();
host.dispose();
```

`declaration` 为 `{protocol:'wimipet/1',module:'D',implementationVersion:'0.2.0',capabilities,limits}`。能力字符串是本 D 绑定的标识，装配可显式映射其他模块自己的能力声明；不能仅匹配版本字符串。

默认要求 transport.declaration 同时具备 `message-view`、`user-input`、`observation-policy`、`resource-bridge`、`cancel-request`、`studio-entry`。`requiredCapabilities` 可要求额外能力；当前完整 UI 不支持删掉这些必需能力后继续假装完整可用。未知必需能力返回 unsupported-capability。

限制字段是本绑定对根基线的表达：`textCodePoints:4000`、`attachmentCount:1`、`attachmentBytes:2097152`、`attachmentMimes:['image/png','image/jpeg']`；采用 D 与宿主的交集，更小限制会同步显示到界面。即使对端支持多图或 WebP，D 当前也只声明基线；不能自行接受并丢弃扩展内容。

## 注入的提供方

| 对象 | 方法与要求 |
| --- | --- |
| conversation | C 的 `getView({type:'user'})`、`subscribe(viewer,listener):unsubscribe`。不得接调试管理员 snapshot；D 不读取角色私有上下文，也不补取完整 List |
| presentation | 装配只读 `getSnapshot()`、`subscribe(listener):unsubscribe`；包含与 C 一致的 sessionId、roles、上游实际确认的 observationPolicy、mode，及可选 clock。可提供 onUiEvent 记录无正文操作 |
| transport | `declaration`、`request(envelope):Promise<response>`、`cancel(envelope):Promise`。转发根信封，不能把受理当完成；不得吞掉错误 |
| resources | 浏览器资源桥绑定，见下节。只管理引用/字节，不理解消息业务 |

订阅不得在返回前同步回调。D 先订阅再取快照，校验 sessionId/revision 并拒绝同会话 revision 倒退；两个源发生切换时宿主须保证原子一致。暂时不一致时显示 stale 源错误并停止发送，随后一致快照可恢复。D 不把多个源合成一个可编辑权威 List；排序、头像/预览解析属于可丢弃展示投影。

`presentation.roles` 是 D 的本地宿主绑定：`{instanceId,packageId,revision,name,avatarRef?,interactive,position:{x,y,visible,coordinateSpace:'stage-css-px'}}`。同包双实例使用不同 instanceId。avatarRef 由资源桥解析；没有引用则退为名字首字占位。位置已经是装配映射后的舞台 CSS 像素，直接传根 A 的 desktop-physical-px 会拒绝。原始 A Position 的 displayId、scaleFactor、origin 与 anchor 的转换由宿主完成，D 不猜测。

`clock` 默认 live；固定历史回放可显式传 `{mode:'replay',atMs:整数epoch毫秒}`，且只影响气泡展示。D 使用 C 原始 seq 排序、atMs 计算寿命，不在获取消息或刷新 UI 时重新赋时。

## 资源桥绑定

- `prepare(file,{sessionId,requestId,expiresAtMs}):Promise<Attachment>`：只在浏览器适配器内接收 File，实际 bytes 保存与类型/大小验证由桥执行；跨进程传输由桥自己的适配器完成。D 仅做 MIME/大小初筛，演示桥还检查签名，并在浏览器实际解码。
- `preview(ref):受信http(s)或当前浏览器blob地址|undefined`：ref 可以是 avatarRef 或 contentRef。预览地址单独附在展示投影的 previewUrl 上；UserInput 中显式剥离 previewUrl。
- `cancelPreparation({requestId,sessionId})`：取消本地准备任务；任务即使忽略取消，D 的有界包装也会忽略迟到结果并释放未提交引用。
- `retainInFlight(contentRef,sessionId,requestId)`、`finishRequest(requestId,accepted)`：在途引用不得提前释放。确定受理则转为会话保留；确定拒绝可解除在途保留。
- `retainSubmitted(contentRef,sessionId)`：消息源显示期间保持有效。
- `releaseDraft(contentRef)`：幂等释放草稿持有；不得撤销仍在途或已提交的引用。
- `releaseSession(sessionId)`：由装配在该会话结束且消费者已移除引用后释放。facade 不擅自释放共享会话资产。

除 prepare 外，生命周期与查询方法必须同步、有界、幂等且不抛异常；远程资源管理由宿主适配器承接。资源桥必须保证 contentRef 可被 C 注入的 resolver 解析，不是 URL、路径或 File。仅 D 的演示桥可以解析 `demo-resource-*`；真实装配不得使用它冒充 C 的模型资源来源。

取消/超时是传输或本地等待结果，不证明 C 从未受理，也不保证上游停止计费。没有权威终态时资源需保留到会话结束，避免消息或在途模型读到已撤销图片。D 不自动重试；用户明确重试创建新的 requestId，应先查看上游处理事实，避免不确定传输结果造成重复输入。

## 请求、回执和设置

`host.submit({requestId,kind,recipient,text,attachments,expiresAtMs?})` 将业务字段放入根请求信封：

```javascript
{ protocol:'wimipet/1', sessionId, requestId, expiresAtMs,
  type:'UserInput', payload:{kind,recipient,text,attachments} }
// attachments 每项只有 attachmentId/name/mime/sizeBytes/contentRef
```

响应绑定为 `{protocol,sessionId,requestId,payload:{accepted,error?}}`，即根 InputReceipt 的信封形式。错误为根 `{code,message,retryable}`。requestId/sessionId 错配拒绝为 conflict；只在 accepted===true 时清草稿，之后消息仍从 C 获准源出现。输入允许只有图片，不补用户台词、不截断正文、不改写接收对象。

`host.changeSettings(policy)` 发送 `type:'ObservationPolicy'`，payload 为根定义的完整策略；`host.openStudio()` 发送 `type:'OpenStudio',payload:{}`。这两个 type 是 D 的传输方法绑定名，装配可映射到各提供方方法，不是额外业务语义。响应同样保留根公共字段，payload 可带实际 policyRevision 或结构化 error。UI 以 presentation.observationPolicy（必须代表 A/C 上游确认）为实际状态，回执本身不使策略生效。界面预设 10秒/60秒直接映射 10000/60000ms，保留 scope/excludedRegions，并从实际 policyRevision+1 提交；冲突由上游明确拒绝。

默认请求截止为 10 秒，可通过 timeoutMs 配置为 1–300000 整数毫秒。epochNow/monoNow/定时器可注入测试时钟；接收时转为单调截止时间，系统墙钟变化不延长已发等待。`host.cancelPending()` 终结本地等待并向 transport.cancel 发送根信封，`type:'CancelRequest',payload:{requestId:被取消ID}`。取消信封有独立 requestId 和期限，不传 AbortSignal/语言句柄。真实 IPC 的取消确认、终态与提供方计费仍由宿主负责。

`host.invalidateDrafts()` 终结在途 UI 操作与草稿准备，`host.dispose()` 还解除源订阅。新 session 自动失效旧请求；UI 只丢弃展示草稿和体验引用，不改写用户资产。demo/host.js 的权威假源只用于模拟，公开入口不会导入 demo。

## 共同样例与当前验证边界

`summarizeCharacterPackage(package,instanceId)` 消费已验证根角色包的身份与 avatarAssetId，生成摘要，不替代 A/B 完整包校验。自带副本与共享原件哈希一致，浏览器以两个不同实例消费并实际解码头像。标准消息与请求测试使用注入生产者，未运行真实 C 模块；不能据此宣称 B→A→C→D、原生气泡或真实观察暂停完成。
