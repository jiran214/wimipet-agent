# D 模块接口草案 v0.1

状态：本模块已实现的本地适配接口，**未与 A/B/C 协商或联调，不是项目正式协议，也不声明跨模块兼容**。对应 [D0001](../PRD/D0001-companion-ui.md)。本次只修改 D 范围，后续正式协议需各模块独立更新关联需求。

## 装配方式与状态归属

```javascript
import { mountCompanion } from './modules/companion-ui/src/view.js';
// 页面需加载 src/style.css；容器中只挂载一个实例。
const ui = mountCompanion(container, host);
// 解除 DOM 监听、ResizeObserver、过期检查计时器和消息订阅：
ui.dispose();
```

`host` 通过装配注入。UI 不导入其他模块。UI 每次渲染直接调用 `getSnapshot()`；不持有第二份消息数组，不拼接模型输出，也不自行增添消息。`demo/host.js` 是独立场景的消息权威来源，仅供演示，禁止将其作为真实环境的对话缓存再接一份 C 消息源。

展示状态只有面板开合、草稿、附件选择、滚动位置、未读消息 ID 集合、等待标志及气泡布局。接收 Promise 解决只表示受理，最终业务状态/消息仍来自宿主快照。消息发送期间禁用重复提交；重置与销毁使迟到回调失效。宿主也必须按会话/请求 ID 隔离迟到操作，不能仅依靠 D 防护。

## 宿主能力

| 方法 | 语义 |
| --- | --- |
| `getSnapshot(): Snapshot` | 同步返回当前获准快照，字段完整、有序、无重复消息 ID；无需暴露完整 List |
| `subscribe(listener): unsubscribe` | 源变化时调用 listener，无参；不在 subscribe 返回前同步触发；返回退订函数 |
| `submit(UserRequest): Promise<void>` | 成功代表受理；失败 reject，UI 保留草稿。写入消息由宿主管理 |
| `prepareAttachment(file: File): Promise<Attachment>` | 浏览器文件边界适配，由宿主接收 File 并准备引用；UserRequest 中只有普通字段，不能直接传 File 或原生句柄 |
| `changeSettings(SettingsIntent): Promise<void>` | 关联 ID 的设置意图；成功与失败都以 Snapshot.settings 为最终事实，UI 不提前修改 |
| `openStudio(): void 或 Promise<void>` | 打开 B 制作入口，演示只记录 |
| `onUiEvent?(event): void` | 可选的本地复现操作记录，不含正文；不得触发业务状态改变或抛出异常 |

Promise 必须有界返回；具体超时、取消与传输错误映射需要宿主适配器落实，当前 UI 不强行重试，以免重复业务操作。演示的延迟固定 450ms，重置/销毁取消所有延迟任务。

## 数据形状

```javascript
// Snapshot
{
  sessionId: '公开会话标识',
  roles: [{ id: 'stable-id', name: '显示名', mark: 'L', tone: 'moss',
    x: 120, y: 260, visible: true, interactive: true }],
  messages: [{ id: 'message-id', speakerId: 'stable-id',
    speakerName: '发送时显示名', mark: 'L', tone: 'moss',
    kind: 'message', text: '获准正文', at: 1794920000000,
    attachments: [], recipient: 'all' }],
  settings: { observationPaused: false, frequency: 'balanced' },
  processing: 'idle', // idle | working | failed
  mode: '真实宿主 / 模拟宿主的可见标识'
}

// UserRequest
{ requestId: 'ui-...', kind: 'message', // message | story-event
  recipient: 'all', // all 保留为全体，其他值是稳定角色 ID
  text: '输入内容', attachments: [] }

// Attachment
{ id: '上游引用', name: '显示名', type: 'image/png', size: 1024,
  url: 'blob:... 或受信 http(s) 预览地址' }

// SettingsIntent
{ requestId: 'settings-...', observationPaused: true, frequency: 'low' }
```

角色稳定 ID 不得为保留值 `all`。消息顺序以传入数组为准，UI 不按时间重新排序。历史身份由消息中的 speakerName/mark/tone 保留，角色离开也不借用其他角色身份。演示以字母占位头像实现，不将占位图当成真实角色资产。真实头像引用的渲染/安全策略需要 B 与装配层进一步约定。

`at` 是 epoch 毫秒，用于展示寿命；与 C 的逻辑时间、历史回放时间对齐待定。位置必须是舞台内 CSS 像素坐标，由 A/宿主提前转换，UI 只裁剪和避让，不计算身体运动。当前 DOM 舞台不是透明原生桌面窗口。

文本使用 HTML 转义，预览仅接受 blob/http(s) URL。宿主必须只提供受信附件地址，不得向 D 注入任意外部追踪地址或文件系统路径；实际内容类型/恶意文件检查属于上传端。UI 的 MIME 与 5MB 限制只是输入便利校验。附件最多 4 个，是当前本地体验策略，不作为已确认的永久产品上限。对象 URL 由创建它的宿主管理，保证引用在会话展示期间有效，移除草稿附件后可继续保留至会话重置/宿主销毁；演示不会把图片上传。

## 界面策略与待联调项

- 本地策略：最多三气泡、十秒到期、默认 250×156 CSS px，窄区域自适应；碰撞放不下的消息由历史回看。不是新增的确认需求。策略定义在 `src/model.js`。
- 面板打开时零气泡；关闭后只有仍在寿命范围内的消息可显示。未读提示以当前获准视图计算，不向 C 请求完整 List，不推断私聊权限。
- 正式接入待协商：稳定 ID 与全体地址、消息修订/删除语义、头像包引用、附件上传与生命周期、错误与取消协议、设置版本与频率枚举、位置/DPI/多屏坐标、B 打开入口。
- C 必须先过滤消息可见性；A 负责真实观察/位置；B 负责资产与制作。D 不添加模型端点或 API Key 设置。无真实宿主时保留清楚的模拟标识，不提供“已接通”的开关。
