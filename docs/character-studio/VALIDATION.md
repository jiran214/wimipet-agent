## 自动检查

环境：Windows PowerShell，Node.js v22.22.1、npm 10.9.4。模块目录执行 `npm test`，10 项通过、0 失败：

1. 原创固定 PNG 尺寸、JSON 往返、离线资源引用可读。
2. 缺帧、无效时长、重复动作与无效包版本可被发现。
3. PNG 签名/CRC、尺寸不一致、接触点越界、位移语义错误可被发现。
4. 草稿和确认快照隔离、确认递增、校验失败保留原快照。
5. 模拟成功只产生候选；采用单动作不覆盖其他动作或确认版本。
6. 模拟失败、取消、忽略 AbortSignal 的迟到结果、放弃候选与重试。
7. 无效候选与冲突资源拒绝原子写入，多角色互不覆盖。
8. 错误包结构、非法 JSON、超大包可被拒绝。
9. 提供方无效响应进入 failed；取消后马上重试不会被旧响应覆盖。
10. 启动独立 HTTP 服务，读取界面/配置/固定包；私有文件不可访问，错误 Origin 拒绝，真实适配器未配置时返回明确错误。测试结束停止自己启动的服务。

另执行 `node --check demo/app.mjs`、`node --check server.mjs` 和 `git diff --check` 通过。没有真实模型、账号或跨模块依赖参与测试。PNG 结构/校验和检查与浏览器图片解码分开执行，不将结构检查等同于视觉质量。

- 真实生图：未验证，无模型凭据或具体适配器。只提供配置入口、通用 HTTPS 请求/响应契约、超时和取消传播；真实模型是否停止计费/计算由提供方决定。
