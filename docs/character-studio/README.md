# 角色制作台：独立运行与体验

主责：B / character-studio。依据 [B0001](../PRD/B0001-character-studio.md)。这是本模块的本地实现，不依赖 A/C/D，也未完成跨模块兼容验证。

## 环境与启动

Windows PowerShell，Node.js 22 或以上，现代 Chromium / Edge / Chrome。没有 npm 第三方依赖，无需安装包或模型密钥。

```powershell
cd C:\Users\jiran\.codex\worktrees\a8f1\wimipet-agent\modules\character-studio
npm start
```

在浏览器打开 <http://127.0.0.1:4312>。终端按 `Ctrl+C` 停止；服务仅绑定本机。端口冲突时先 `$env:PORT='4313'` 再启动；换端口相当于新的浏览器存储来源。

核心为 `src/core.mjs`，演示直接导入它。`server.mjs` 提供静态资源和可选生成适配器转发；不保存用户资源到服务器。浏览器 localStorage 保存独立项目的草稿与确认快照，容量受浏览器限制；空间不足时界面会持续提示仅在内存中。关闭前请导出。角色文件不应存放在服务公开的 `demo/src/fixtures` 中。

## 无密钥固定场景

1. 初始显示原创固定角色“苔苔”、4 张 160×160 透明 PNG 和一个呼吸动作，素材版本 `original-momo-v1`。固定文件在本模块 `fixtures/`，无需下载。
2. 点击“新建”，填写名字、自由人设、形象说明，保存草稿。角色数量没有双角色限制。新角色尚无已确认版本，因此导出不可用。
3. 点击“导入固定动作”，进入候选；或导入 `fixtures/idle-1.png` 至 `idle-4.png`，文件名自然排序。也可独立导入头像和参考图。
4. 连续播放、暂停、从头回放、拖动逐帧条，检查轮廓、透明边缘、首尾、裁切和接触点。编辑当前帧时长会自动暂停。名称、含义、循环、位移模式、步幅和接触点可修改，点击“应用到当前预览”。接触点目前通过 JSON 编辑，橙点展示第一个点。切换动作下拉框可检查不同动作的切换。
5. 点击“采用候选到草稿”，再点击“检查草稿”和“确认完整角色版本”。结构与图片解码错误会阻止确认。确认版本号递增，后续草稿编辑不修改它。
6. “导出已确认角色包”下载单文件 JSON，图片内嵌，无需手工整理资源。选择该文件“重新导入角色包”，创建独立项目，确认内容应完整保留。
7. 切换项目、刷新页面，查看人设和资产是否恢复。点击“恢复样例副本”会新增固定样例项目，**保留所有原项目**。本工具不提供静默清空用户资产的重置。

调整仅修改元数据与帧时长，不含图像修复、画布裁切或重新对齐编辑器。动作预览使用固定画布中心对齐；位移仅记录为资产语义，不模拟真实桌面移动。

## 生成任务与失败恢复

- “模拟 · 固定成功”：等待约 1.2 秒，返回同一组固定素材；动作描述写入候选含义。它验证流程，不证明生图效果。
- “模拟 · 固定失败”：返回可复现错误，草稿与确认快照不变。切换成功模式可重试。
- 生成后“放弃候选”不改草稿；“采用候选”只改草稿中的单个同标识动作；“确认完整角色版本”才更新快照。
- 处理中可取消；取消与迟到响应不会采用结果。切换角色或离开页面会取消任务。候选是临时状态，不随刷新保存。真实模式重试不保证相同输出。
- 正在播放或编辑时，可随时“从头回放”。恢复样例不触发真实模型。

## 可选真实生成适配器

首版提供通用 HTTPS 适配器接入点，**不内置任何厂商生图 SDK，也未验证真实模型**。需要自行提供符合 [接口契约](CONTRACT.md) 的 HTTPS 服务，把具体厂商的输出转换成 PNG 帧与动作元数据。

```powershell
$env:STUDIO_GENERATOR_URL='https://your-adapter.example/generate'
# 可选：在当前终端设置凭据，不写入源码、包、体验记录；勿提交真实值
$env:STUDIO_GENERATOR_KEY='<适配器密钥>'
npm start
```

界面选择“真实适配器 · 未验证”。只向该适配器发送动作描述、动作标识、名称和所选参考 PNG；不发送人设、个人桌面或截图。凭据只存在启动服务的环境变量中，由服务添加 Authorization；配置接口不返回地址或密钥。请求超时 60 秒，取消会中断上游 HTTP 请求（提供方是否停止计费或计算需要其自行支持）。修改配置须重启服务。停止后可用 `Remove-Item Env:STUDIO_GENERATOR_KEY -ErrorAction SilentlyContinue` 清除当前终端变量。

真实结果仍需独立检查跨帧形象、循环与切换、透明边缘、遮挡、材质连续性；接口返回成功不等于效果通过。

## 检查与反馈

```powershell
npm test
```

自动检查不使用网络账号、其他模块或真实模型。详见 [验证记录](VALIDATION.md)。可用 `node fixtures/build-sample.mjs` 重新生成同版本原创固定素材。

界面填写“人工体验实际结果 / 问题帧”后点击“导出体验记录”，得到场景、程序与素材版本、操作类型、模式、确认版本、预期、实际结果和必要错误。操作日志不记录人设、图片、密钥或截图；用户手填文字请分享前自行检查。记录是当前页面会话，不随刷新累积。

已知限制：浏览器本地存储不是正式资产库；没有多设备同步与项目删除入口；仅 PNG 序列，暂不支持 GIF 解码、精灵图拆分；静态接触点首版只展示第一个；真实提供方与消费者接口尚待联调。
