# 角色制作台：独立运行与体验

主责 B；需求 [B0001](../PRD/B0001-character-studio.md)、[B0002](../PRD/B0002-统一角色包交付.md)。公开边界唯一依据为根 [AGENTS.md](../../AGENTS.md) 的 `wimipet/1`。当前版本 0.2.0，独立运行，无 A/C/D 依赖；消费者与模型效果仍需独立验收。

## 启动、停止与存储

Windows PowerShell，Node.js 22+，现代 Chromium/Edge/Chrome。零第三方运行依赖，无需安装包或模型密钥。在仓库目录：

```powershell
cd modules/character-studio
npm start
```

打开 <http://127.0.0.1:4312>，Ctrl+C 停止。端口冲突时设置 `$env:PORT='4313'`，或 `$env:PORT='0'` 自动分配；以终端实际打印 URL 为准。服务只绑定 127.0.0.1，启动及界面显示程序版本、协议、实例标识和模拟/真实适配器模式。换端口会使用不同的浏览器存储来源。

当前项目草稿和确认快照保存在浏览器 localStorage 的 `wimipet.character-studio.v2`；旧版 v1 项不删除、不自动转换为运行包。浏览器配额不足时持续提示仅在内存中，请确认后导出备份。关闭服务不删除用户项目。损坏的旧存储不会被静默覆盖。

## 无密钥体验

1. 默认加载共同角色包的固定副本 `fixtures/common-v1.character.json`，与根共同样例逐字节相同，来源 a24c406。含 idle 与 wave，画风不同只用于协议交换；不用于真实模型质量评审。
2. 可直接检查、确认、导出、重新导入；包身份保持 `contract-sample-moss`，确认从 revision 1 递增至 2，导入不额外递增。重新导入会创建独立编辑项目，不覆盖原项目。
3. “新建”后自由编辑名字、人设、形象说明，保存草稿。可导入头像和参考 PNG。参考图仅用于创作/生成，新导入且未被动作或头像引用的创作素材不进入运行包；从已确认运行包导入的全部 PNG 会保留。
4. “导入固定动作”得到有完整明确元数据的 idle 候选；“导入 PNG 序列”得到未确认语义的自定义候选，按文件名自然排序。不得自动假定该素材可悬挂或攀附。
5. 在动作下拉框选择动作，连续播放、暂停、从头回放或逐帧检查。填写动作名称、含义、允许状态（英文枚举逗号分隔）、优先级、接触类型；逐帧填写像素接触点 JSON，例如 `{"x":80,"y":137.6}`。坐标以整张画布左上角为原点，允许包含边界。
6. 编辑帧时长或接触点时暂停并保护输入；点击“应用到当前预览”提交元数据，保留所选帧。修改后请先应用；选择另一帧/动作或从头回放会放弃尚未应用的表单输入。暂停输入未应用时不能恢复自动播放。
7. “采用候选到草稿”只改变草稿；“检查草稿”列出运行配置拒绝原因；“确认完整角色版本”真实解码并校验成功才更新快照。悬挂等身体语义缺失时需创作者明确填写，不能由装配猜测。
8. “导出已确认角色包”始终输出真实 `wimipet/1`，包含头像与嵌入 PNG、动作描述、允许状态、接触类型、优先级及逐帧接触点；当前未确认草稿不进入导出。
9. “恢复样例副本”创建新的创作项目与包身份，保留全部原项目；每次切换/恢复创建新的会话并隔离旧异步结果。可重复预览与导出体验记录。

创作草稿仍可保留 2048×2048 以内 PNG、非整数时长或 root-motion；这些不代表运行配置可用。统一运行配置仅接受不超过 512×512、单资源二进制不超过 2MiB、总 UTF-8 包不超过 32MiB、整数 16–10000ms、in-place 等根规范限制。非零创作步幅也会明确拒绝，不能静默丢掉位移。必须有 feet 循环 idle，允许 standing/falling/dragging；不能把它当作躺卧/悬挂资产。

旧 `character-studio/0.1` 导出文件可在同一导入入口显式载入为未确认草稿。旧动作级归一化接触点不自动映射或猜测为运行语义；需要逐帧填写像素接触点和动作身体元数据后才能确认。旧浏览器存储仍保留，必要时用原版本导出再迁移。

## 模拟与真实生成

模拟成功等待约 1.2 秒后复用固定 PNG，不生成新画面；固定失败可重试。任务有 60 秒截止时间，可取消；编辑已保存草稿、切换/恢复项目或退出后，旧候选不能采用。候选只保留在当前会话，生成、采用、确认是三个不同阶段。

真实生图只提供通用 HTTPS 适配器入口，未接入具体厂商、未验证质量：

```powershell
$env:STUDIO_GENERATOR_URL='https://your-adapter.example/generate'
$env:STUDIO_GENERATOR_KEY='<适配器密钥>' # 可选，仅当前进程环境；不提交真实值
npm start
```

适配器需转换厂商返回为本模块文档中的规范动作候选，不是任意厂商 URL 可直接使用。界面选择真实模式后才发送动作描述、动作 ID/名称和所选参考 PNG，不发送人设或桌面截图。凭据只在本地服务环境中，由服务添加 Bearer；不返回给网页、角色包或反馈。配置变更需重启。停止后可 `Remove-Item Env:STUDIO_GENERATOR_KEY -ErrorAction SilentlyContinue`。

取消中断本地等待和上游 HTTP 请求，不承诺提供方停止计算或计费。真实结果仍需检查形象一致性、遮挡、透明边缘、循环与切换，不能用模拟成功代替评审。

## 检查、固定导出与反馈

在模块目录执行：

```powershell
npm test
npm run export:sample
```

第二条通过同一公开核心导入共同样例、确认至 v2、导出并写入固定位置 `fixtures/exports/common-v1.export.character.json`，回执记录来源和 SHA256。输出是供 A 加载的真实角色包，不是格式转换伪样例；**当前不因此宣称 A 消费通过**。

公开能力与方法见 [CONTRACT.md](CONTRACT.md)，实际结果见 [VALIDATION.md](VALIDATION.md)。界面填写人工实际结果/问题帧后可导出反馈，含场景、版本、包身份、会话、步骤、模式和必要结构化错误，不自动收集人设、图片、密钥或个人截图；用户手填内容分享前自行检查。

限制：仅 PNG 序列，没有 GIF 解码、精灵图拆分、图像修复或画布裁切编辑；接触点现由 JSON 编辑；没有多设备同步和项目删除入口。内部草稿、外部运行包与模型效果验证分别记录。
