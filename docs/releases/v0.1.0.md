## 装配与配置

- A 身体核心和 C 互动核心由单 asyncio 线程拥有；HTTP 线程通过线程安全调度转发。
- B 制作台作为独立子进程，导出的确认包经 A 实际 PNG 解码后注册到 C；D 正式 host/view 消费 C 获准视图，不使用 D demo 消息源。
- C 使用 OpenAI Python SDK `client.chat.completions.create`，支持兼容服务 base_url、模型、密钥、文字与图片 data URL，错误不回退为模拟成功。
- `.env.default` < `.env` < 进程环境。`.env` 已写入本地小米配置且被 Git 忽略；默认文件不含密钥。
- 图片资源保留至会话结束；未提交草稿可释放；为不确定受理结果保守保留资源。会话容量限制为 64MiB。
- 网页模式明确拒绝恢复桌面观察，不伪造截图。身体真实执行反馈按 A 事件返回 C。

## 本轮发现并修复

- Windows 换行使共同包哈希不同：增加 `.gitattributes` 固定 JSON LF，保留字节一致性测试。
- HTTPServer 默认复用端口与 Windows 独占绑定冲突：明确关闭 reuse，并拒绝连接旧制作台实例冒充启动成功。
- D/C 策略和取消字段不同：在装配层显式映射，不改写业务语义。
- D 的固定演示超时不适合真实模型等待：装配请求期限调整为 90 秒，SDK 请求超时默认 60 秒。
- 关闭页面不等于退出宿主：提供“退出陪伴”，清理 C/A、图片和自有 B 子进程。

## 已知边界

本版是网页陪伴舞台，尚未将 A 原生透明桌宠与 D 气泡整合；原生穿透、跨屏 DPI、桌面采集排除未做本轮产品验收。序列帧显示使用本地帧轮询，尚未验证复杂高帧率资产的观感。真实生图、长期记忆、安装包不在本轮范围。

本地提供的模型密钥返回 401，需要有效权限后再做真实对话、视觉理解和多角色效果评审。加入角色会取消旧轮次生成，这是 C 当前版本行为；聊天和运行角色随程序退出释放。
