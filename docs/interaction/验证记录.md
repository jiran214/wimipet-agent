## 实际启动与浏览器操作复查

启动命令为 `python modules/interaction/demo/server.py`，服务实际响应 <http://127.0.0.1:8763>。使用 Playwright CLI 打开浏览器，按页面控件操作；这是代理执行的界面流程复查，**不是用户人工体验评价或真实陪伴效果评审**。

| 操作 | 实际观察 |
| --- | --- |
| 分享固定图片 | 一条公开图片，三个角色差异化固定台词，三个动作 requested |
| 仅给苔苔发秘密，再检查火花上下文 | 火花实际模型输入没有秘密文本 |
| 自动接话 | 有限轮次结束，显示停止；机制级插话和取消另由核心测试覆盖 |
| 暂停后请求查看桌面，再恢复观察 | 暂停无新消息，恢复后显示固定画面事件 |
| 火花设为失败并向全体输入 | 火花 failed，苔苔 / 星轨 done，会话继续 |
| 苔苔设为超时并向全体输入 | 其他角色先 done，约八秒后苔苔 timeout |

| 注入故事 | List 出现导演事件及角色固定回应 |
| 下载诊断 | 生成 interaction-diagnostics.json，含步骤；检查上传图片数据已省略，不含 data:image/ 内容 |
| 恢复样例后再次分享图片 | 消息归零，再次产生四条消息，恢复三角色正常行为 |
| 1440px 桌面 / 390px 移动视口 | 截图复查桌面排版；移动视口页面宽度未超过窗口，无横向溢出 |
| 重复启动同端口 | 独占绑定拒绝第二服务，避免读取旧实例状态 |

本地复查产物在 `modules/interaction/output/playwright/`，CLI 快照在该模块 `.playwright-cli/`，均已忽略、不提交。用户可按 [运行与验收](运行与验收.md) 重复操作并导出自己的结果。服务重启期间旧页面短暂连接错误不视为模型错误；初次 favicon 404 已用内联图标消除。

Windows 复测发现默认 HTTPServer 的地址复用可能允许两个本地实例绑定相同端口，已增加独占绑定；复测得到 WinError 10048 拒绝第二实例，随后补充清晰的中文启动错误。工具进程中 Ctrl+C 未可靠传给子 Python，因此测试服务通过确认 PID 后清理；核心 close/reset 的任务释放由自动测试验证，用户真实终端 Ctrl+C 退出体验仍应人工复核。
