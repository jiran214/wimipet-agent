# C 模块公开入口与 wimipet/1 映射

规范唯一来源为根 [AGENTS.md](../../AGENTS.md)。本文件只说明 C 的方法映射，不定义候选协议。实现版本 `interaction/0.2.0`；旧 `c-lab/0.1` 接口已由本轮迁移替换，旧调用方必须更新，不能只更换版本字符串。

## 宿主直接入口

将 `modules/interaction/src` 加入 Python 搜索路径，导入 `public.create_interaction`，**在宿主选定的运行中 asyncio 循环创建**：

```python
core = create_interaction(model=model, resolver=resources, body=body, capture=capture)
handshake = core.getCapabilities()
unsubscribe = core.subscribe({"type": "user"}, listener)
initial = core.getView({"type": "user"})
receipt = await core.dispatch(request_envelope)
unsubscribe()
report = await core.close()
```

完整可执行例子是 `modules/interaction/demo/host_example.py`，命令 `python demo/host_example.py`（工作目录 `modules/interaction`）。它通过正式入口消费固定共同包、模拟 A 加载结果、图片无正文和重复请求，检查视图订阅并关闭；不启动实验室 HTTP，也不导入其他模块。

所有公开状态调用在同一个 asyncio 循环运行。Tk/其他线程不能直接调用；宿主可用 `asyncio.run_coroutine_threadsafe(core.dispatch(envelope), loop)` 转发，getView/subscribe 也应包装为该循环内的协程调用。模块会检查循环归属。Python 回调和退订函数只用于进程内；跨进程 JSON 转发与订阅连接由装配实现，不能序列化语言对象。

## 握手、视图和订阅

`getCapabilities()` 返回根规范字段 protocol/module/implementationVersion/capabilities/limits，并附依赖可用性与模拟/真实模式。limits 明确 4000/20000 Unicode 码点、单图 PNG/JPEG 2MiB、去重记录容量。缺 resolver、身体或策略确认能力时相应请求明确失败，不以固定动作或假成功补偿。

`getView(viewer)` 和 `subscribe(viewer, listener)` 的 viewer 为 `{"type":"user"}` 或 `{"type":"character","instanceId":"…"}`。角色必须已注册。快照原子返回 `{sessionId, revision, messages, processing}`，无管理员上下文。每条消息遵循规范 Message，历史 speaker 名称保留，不因重新加载而改变；atMs 取 epoch 时钟，seq 决定顺序。

subscribe 返回前不会同步回调；更新通过循环 `call_soon` 投递，只读副本不影响权威 List。先订阅再取快照，宿主按 `(sessionId, revision)` 去重；回调可能收到相同最新 revision，不应自行维护可编辑消息副本。退订后已排队通知也不执行；移除角色注销该角色订阅；重置后现有获准订阅收到新会话；close 注销所有订阅。异常 listener 不影响会话，并在管理员诊断中计数。

processing 是只读处理摘要：过滤后的 tasks、动作事实 actions、auto，以及 observation 的 confirmed/requested/analysisPaused/error。用户能看全部私聊，角色仅能看获准消息和处理任务。公开生成只使用公共历史；私聊按本轮完整接收范围再次过滤，防止私聊泄露到公开接话。

`diagnostics()` 是管理员专用权限，含实际模型上下文、实例快照和步骤，**不得作为 D 或其他角色的消息流**。实验室分别从 `/api/view` 取正式用户视图、从 `/api/state` 取管理员诊断；生产宿主直接用上述公开方法。

## 请求入口

`await dispatch(envelope)` 接受根规范公共字段 `protocol/sessionId/requestId/expiresAtMs/type/payload`，返回携带原 requestId 的 C 事件信封。UserInput 使用 InputReceipt，其余命令使用 Receipt；payload 为 `{accepted, error?, …}`。结构化 error 使用根规范基础 code/message/retryable，不输出私有模型响应。

| type | payload 与作用 |
| --- | --- |
| `RegisterCharacter` | `{package, loaded}`；loaded 是 A 的 CharacterLoaded payload，含 instanceId/packageId/revision/supportedActions/supportedPostures。C 校验身份版本与动作关联并复制快照，不替 A 解码帧。初次注册与显式重新加载共用此入口，失败保留旧快照。 |
| `UserInput` | 规范 `{kind, recipient, text, attachments}`。recipient 是 all 或单个 instanceId；图片无正文合法，空正文保持空。受理仅代表入队，模型结果由正式视图取得。 |
| `StartAutoConversation` | `{rounds:1..12}`，默认 3；当前实例集合轮换，有限结束。 |
| `StopConversation` | `{}`；停止会话生成，保留同一 List；不伪造身体被打断。 |
| `CancelRequest` | `{targetRequestId}`；取消 C 已接收请求所属在途资源/生成/策略任务。取消不是撤回已提交消息，也不代表远端模型停止计费。身体执行取消须由宿主向 A 发起，再以 ActionResult 消费事实。 |
| `SetObservationPolicy` | payload 即规范 ObservationPolicy。版本必须递增，失败不回滚版本号复用。 |
| `ObserveDesktop` | `{source?:"window", force?:bool}`；force 仅绕过冷却，不绕过暂停和确认。自身输出来源明确拒绝；新场景即使冷却中也使旧结果失效。 |
| `RemoveCharacter` | `{instanceId}`，移除后不再发布其在途回复；保留已有消息的历史身份。 |
| `ResetSession` | `{}`，返回 `newSessionId`，资源释放失败另报 `cleanupError`；新会话清空体验 List/诊断、释放旧会话引用，并暂停 C 分析，要求重新确认观察策略。 |
| `ActionResult` | 消费 A 的反馈事件，公共 requestId 关联原动作命令；payload 为 instanceId/status/reasonCode?/message?。各状态事件须带不同 eventId。 |

请求按 `(sessionId,requestId)` 去重：相同完整信封返回原回执、不同内容 conflict，处理中重复请求等待同一回执。超过 expiresAtMs 或接收时算出的单调截止返回 stale；不因墙上时钟回拨延长截止。有效记录保留至截止，容量不足 unavailable，不逐出有效记录。重置后的旧会话请求始终 stale，不重放。

ActionResult 同一动作 requestId 会有多个状态，因此按 `(sourceInstanceId,eventId)` 去重，校验事件 source=A、sourceSeq/atMs 及实例关联。重复事件不重复写入消息，冲突或非法转换明确拒绝；保留记录至少至该事件 expiresAtMs。事件信封有效期应由 A 针对本次事件设置，不能将很久之前动作受理截止误当成新反馈事件的有效期。

## 注入依赖

- `async model.generate(roleSnapshot, visibleMessages, sessionId) -> {text?, actionId?}`。roleSnapshot 只含实例身份、人设及已加载 supportedActions，不含凭据。输出动作只能从该集合选择，允许纯动作或保持安静。模型/资源/采集调用受取消与单调截止约束，迟到结果不发布。
- `async resolver.resolve(contentRef, sessionId) -> bytes`；采集还使用 `async describe(contentRef,sessionId) -> Attachment`。引用不直接解析为路径/URL；桥负责字节、类型/大小与生命周期。C 再检查声明大小和媒体签名；提供方适配器编码图片字节。可选 `releaseSession(sessionId)` 在重置/退出调用。示例 MemoryResources 是内存替身，正式资源桥由宿主注入，解码安全策略归该桥。
- `async body.send(ActionCommandEnvelope)` 仅负责投递，返回不等于动作接受。后续 A 事件通过 dispatch(ActionResult) 进入 C。状态 requested→queued/accepted/rejected，queued→accepted/rejected/interrupted/failed，accepted→completed/interrupted/failed；终态不可复活，循环动作不自行 completed。传输失败保留 requested 并记录 requestError；不会伪造 failed 身体事实。
- `async capture.applyObservationPolicy(policy) -> {policyRevision}` 与 `async capture.capture(CaptureRequestEnvelope) -> CaptureResultEnvelope`。策略同步期间 analysisPaused=true，confirmed 保留最后实际确认值；失败公开错误且继续禁止分析。截图核对 sessionId、sceneId、policyRevision、capturedAtMs/source/rect/contentRef；模型结束再核对版本。原生排除 targetId 登记由宿主/A 完成，无法保证排除须由采集端 unavailable，C 不伪造保证。

可注入 `clock()` 单调秒、`epoch_ms()` UTC 整数毫秒、timeout、dedup_capacity。回放时宿主须显式声明时钟；epoch 不从单调时间换算。

## 关闭与验证边界

`await close()` 取消任务、清理订阅与当前会话资源，并返回 closed/pendingTasks/providerWorkers、resourceErrors/resourceCleanupPending/resourceCleanupDelegated。不合作的依赖可能残留任务，不能把 report 中的非零值当作成功释放。资源桥释放失败会列出待清理会话并在关闭时重试，未提供释放方法的桥由宿主清理。未知提供方 worker 数为 null，不能解释为零。真实标准库 HTTP 在线程内，20 秒网络超时前可能仍有 worker；取消不强制终止远端请求/计费。A/D 模块本身及其进程由宿主管理。

当前只完成 C 与假依赖协议检查，共同包副本字节一致；没有运行真实 A/B/D 消费者，未达到根规范“真实消费者用共同样例通过”的最终门槛。宿主线程/IPC、实际资源桥、原生采集排除、A 反馈和 D 订阅适配仍需协调集成。
