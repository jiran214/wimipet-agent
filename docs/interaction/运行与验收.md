# C 模块互动实验室 / wimipet/1

环境：Windows、Python 3.11+。首次安装 `python -m pip install "openai>=2.0,<3"`；离线体验不需要模型密钥或其他模块。模块依赖配置在 `modules/interaction/pyproject.toml`；当前实现版本 `interaction/0.2.0`。下面命令的工作目录均为仓库内 `modules/interaction`。

## 启动与停止

```powershell
python demo/server.py
```

打开 <http://127.0.0.1:8763>。端口被占用可加 `--port 8764`，自动检查推荐 `--port 0` 让系统分配临时端口，以终端输出为准。终端和页面都显示版本、进程实例标识和真实/模拟模式；先确认实例，避免误连旧服务。回环地址独占绑定，不接受第二个同端口实例。

停止：启动终端 `Ctrl+C`。关闭时打印 pendingTasks/providerWorkers 报告，非零表示底层资源仍需宿主处理。刷新保留服务中的当前会话，重启不恢复。该 HTTP 服务没有远程认证，只是本地单用户调试工具，不可直接部署为正式远程服务。

## 固定样例与五分钟操作

实验室自带共同包的**字节一致固定副本** `fixtures/character-package.v1.json`，来源为根规范提交 `a24c406` 下的共同样例（SHA256 `d7d6d9b8d731f37aecc4e436c0d48b9aec0efe464d43aa396872f590f14f9eaf`）。不依赖其他模块私有目录；测试只读根共同文件并核对一致性。两个实例 one/two 加载同一包，第三个为明确标记的本地人设变体。加载和身体都是本模块替身，不能视为真实 A 已加载/解码。

1. **图片无正文**：留空输入框，点“分享固定图片”。UserInput.text 保持空；出现一条用户图片与三条固定回复。角色动作仅为已加载 idle/wave，固定模型优先选非循环动作，不预设 nod/look。
2. **私聊隔离**：选 `instance-one · 私聊` 发送“蓝色月亮是秘密”。右侧切到 two，实际模型输入不含秘密。再对全体发言或自动接话，检查 one 的公开轮次输入，也不含私聊。页面是管理员调试权限，能看用户全部消息，不是其他角色的消息流。
3. **输入与草稿**：“选择图片”只准备附件，点发送才提交，可不填正文。支持一张 PNG/JPEG、2MiB，正文 4000 Unicode 码点；失败保留草稿和附件，不自动改为全体。只有 InputReceipt.accepted 后清空。取消未提交附件释放引用，已提交引用保留本会话。
4. **人设与实例**：每个实例编辑 20000 码点以内人设并应用，模拟重新加载运行快照，不改共同包源文件。固定台词不验证人设效果。移除角色后，其在途结果不发布；恢复样例可重新创建。
5. **自动交流与插话**：默认三轮，上限十二轮。“停止 / 取消”结束生成；发文字插话优先取消旧轮次。任务区也可点“取消此请求”。消息仍在同一 List，用户可追问。导演按钮在输入为空时明确填入可见故事起点，使用 story-event；图片发送不会填假用户台词。
6. **完整动作事实**：动作先是 requested；可点“排队→接受→完成”或“排队→打断/失败”，也可直接拒绝。历史显示完整路径，终态不复活。循环动作不能自行完成。所有按钮都是假身体事件，未接通 A 的实际执行。
7. **策略确认**：观察区显示上游已确认 revision 和数值。选“慢确认”或“拒绝策略”体验 pending/失败；同步期间 C 禁止新分析，不能把勾选视为已生效。拒绝时仍展示旧 confirmed 和可见错误。恢复正常确认后再观察；暂停再恢复使旧 revision 画面失效。scope 是传给模拟采集端的值，未采集真实桌面。
8. **失败恢复**：角色选择“模拟失败 / 模拟超时 / 保持安静”并应用，全体输入后其他角色继续；超时默认八秒，失败与安静有独立状态。真实模型线程限制见下文。
9. **重置与重放**：“重放上次输入”用新 requestId 重复最近已受理输入；“恢复样例会话”生成新 sessionId，释放旧附件引用并取消旧任务，恢复固定角色与观察策略。只清理内存体验数据，不删除用户文件，不暗示长期记忆已实现。
10. **记录结果**：填写实际/预期差异并点“保存诊断 JSON”。导出版本、实例、会话、步骤、正式用户视图、模型任务和上下文；包含私聊文字及资源引用，不包含图片字节、密钥或自动个人截图。请自行决定分享范围。


宿主例子直接使用 `src/public.py`，展示握手、RegisterCharacter、图片无正文、重复请求、subscribe/getView 和关闭。它是 C 的假依赖例子，不是统一装配。Node 仅用于可选前端语法检查，运行不需要 Node。接口与线程说明见 [接口与状态](接口与状态.md)，实际结果见 [验证记录](验证记录.md)。

## 可选真实模型

```powershell
$env:INTERACTION_MODEL_URL = 'https://你的完整端点/v1/chat/completions'
$env:INTERACTION_MODEL = '支持图片和 JSON 对象响应的模型名'
# 通过已有安全方式注入 INTERACTION_API_KEY，不要写到角色包或源码。
python demo/server.py --real
```

未配置时明确失败，不回退假模型。提供方适配器从注入 resolver 取得允许的图片字节并编码，不把 contentRef 当 URL。角色人设、可见消息及用户主动分享的图片会发送到所配置服务；桌面仍是固定模拟图。通过 OpenAI SDK Chat Completions 调用服务，模型错误不写原始私有响应。重试不保证相同输出。

装配阶段提供的小米配置返回 401，因此供应商端到端兼容、视觉理解、自然接话、角色差异与陪伴感**尚未验证**。真实 HTTP 在线程中，任务取消不强杀线程或停止远端计费；默认 60 秒网络超时前 close 可能报告 providerWorkers，退出也可能等待线程。必须将机制测试、代理浏览器检查、用户人工体验和真实效果评审分别记录。

统一产品入口见根 README；新的 OPENAI_BASE_URL、OPENAI_MODEL、OPENAI_API_KEY 优先于本模块旧 INTERACTION_* 变量。模块独立入口不会自动读取根 .env，统一装配入口负责读取。
