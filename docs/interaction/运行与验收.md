# C 模块互动实验室

本实现只属于 `modules/interaction/`。Python 3.11+，仅标准库，无需安装依赖或其他模块。浏览器建议使用当前 Chrome / Edge。模块依赖配置位于 `modules/interaction/pyproject.toml`。

## 启动与停止

在仓库根目录的 PowerShell 运行：

```powershell
python modules/interaction/demo/server.py
```

浏览器打开 <http://127.0.0.1:8763>。端口占用时加 `--port 8764`。在启动终端按 `Ctrl+C` 停止：关闭服务器、取消会话任务、清理事件循环。调试工具只绑定回环地址，单用户、单内存会话；不要将此 HTTP 服务作为正式远程接口部署。刷新页面保留服务中的会话，重启不保留。

无需密钥即能操作三个人设、文字、图片、导演事件、有限自动接话、私聊调试、观察和动作反馈。用户可移除参与者、编辑人设；修改样例 `fixtures/roles.json` 并重启可加载任意数量角色，不受三个角色限制。角色 ID 应唯一；`actions` 是已有动作名称集合。

## 五分钟体验

1. 点“分享固定图片”：出现一条公开图片消息，三个角色产生不同的固定台词及动作请求。固定图片是模块自带代码绘制的 PNG v1，非模型生成、非用户真实桌面。
2. 将接收范围切成“苔苔 · 私聊”，发送“蓝色月亮是我们的秘密”。右侧检查苔苔实际输入能看到私聊；检查火花 / 星轨看不到。随后切回全体说话或自动接话，公开轮次的实际输入也不含私聊。页面本身是用户/管理员视图，能看到全部会话。
3. 点“让角色接着聊”：默认三轮，每轮一个角色依序读取此前公开交流，结束后显示停止。上限 12 轮；可随时“停止 / 取消”或发送文字插话。公开轮次不使用私聊上下文，私聊追问保留同一 List 中的可见经历。
4. 注入故事事件，再问“刚才发生了什么”：检查实际输入中的事件。固定模式仅引用末条可见输入，不能证明真实故事理解能力。
5. 点“请求查看桌面”：显示明确标注的模拟绿植画面及回应。暂停观察后再点击不产生新采集。窗口变化经过冷却（默认 10 秒），手动查看可绕过冷却；改变场景或暂停会让在途画面与视觉模型结果失效。桌面与当前窗口两个范围仅验证接口传参，未接通实际截图约束。
6. 在某角色下选择“模拟失败 / 模拟超时 / 保持安静”并点“应用”，发送全体消息：其他角色继续处理。超时默认 8 秒，正常固定回复约 0.6 秒；错误区显示 failed / timeout，安静显示 silent。
7. 在动作区点“拒绝”：状态变为 rejected，只有所属角色能看到反馈；不会记作完成或触发自聊。正常路径必须先接受再完成。这是人工驱动的假身体，不代表 A 已执行。
8. “重放上次输入”重复用户最近输入；“恢复样例会话”取消任务、清空体验 List / 诊断并恢复三角色和默认观察配置，不删除任何用户文件。可重复以上流程。
9. 可“上传图片”，支持不超过 2MB 的 PNG / JPEG，用户主动上传内容仅在当前内存会话中使用；固定模式不做视觉理解。点击“保存诊断 JSON”才下载，包含场景版本、输入步骤、预期、实际备注、消息、任务及动作结果；上传图片的数据会省略，私聊文字会保留，请自行决定分享范围。不自动收集截图或上传诊断。恢复后上传图片不再可重放。

## 真实模型模式（实现适配器，尚未做真实效果验收）

提供一个 Chat Completions 兼容的 HTTPS 适配器，可替换 `generate(role, context)` 依赖；需要模型支持图片和 JSON 对象响应。完整端点、模型名和密钥只从服务端环境读取：

```powershell
$env:INTERACTION_MODEL_URL = 'https://你的服务端点/v1/chat/completions'
$env:INTERACTION_MODEL = '你的视觉模型名'
# 使用你已有的安全方式将密钥注入 INTERACTION_API_KEY；不要写入源码或角色包。
python modules/interaction/demo/server.py --real
```

缺配置时启动明确失败，不回退假模型。真实模式会把当前角色、本轮允许的上下文和用户分享图片发送到所配置服务；桌面仍然是固定截图替身，不采集真实桌面。人设修改在此模式下传入模型。服务端超时、错误响应、无效输出会显示处理失败，不输出原始响应或密钥。适配器拒绝重定向。

取消后不发布结果。标准库 HTTP 在线程执行，取消不会强制终止已发送的远端请求，其底层连接受 20 秒网络超时限制；远端可能仍计费，退出进程可能等待网络线程结束。真实重试不保证相同台词。尚未验证特定供应商兼容性、视觉理解、陪伴感、角色差异和自然节奏。

## 自动检查

```powershell
python -m unittest discover -s modules/interaction/tests -v
node --check modules/interaction/demo/app.js
```

Node.js 仅用于可选的前端语法检查，运行模块不需要 Node。自动测试使用固定模型、假画面、可控策略时钟，不访问外网和个人桌面。细分结果见 [验证记录](验证记录.md)。接口草案见 [接口与状态](接口与状态.md)。
