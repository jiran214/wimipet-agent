## 已确认目标

1. 统一包完整校验、PNG 实际解码、原子载入；同包多个 instanceId，失败保持旧可用版本。共同包必须原样消费，不能以旧 A-display/1 自有包替代验证。
2. 启动握手公开实际能力与限制；根据真实资产推导动作 / 姿态，不要求 idle 虚报悬挂能力。缺姿态时拒绝，公开 structured error。
3. 动作结果保留 queued / accepted / completed / rejected / interrupted / failed 与请求关联；实现重复去重、冲突、超时、取消、会话隔离。
4. 按规范输出图像左上角、帧局部 anchor、物理坐标、显示器原点及缩放，不能让 D 猜测。
5. 观察采用递增 policyRevision、确认暂停、授权范围与排除约束；异步采集不阻塞身体；旧会话 / 旧策略画面丢弃。公开 host targetId 登记，不能保证原生排除时返回 unavailable。
6. 独立体验入口沿用同一核心并迁移公开 facade；自带共同包、慢采集 / 取消体验、重置与反馈。

独立规则 / facade 自动测试、程序化 GUI 与 Win32 检查、人工体验、真实原生效果分别记录于[验证记录](../desktop-world/验证记录.md)。当前迁移实现与具体命令见[接口说明](../desktop-world/接口与身体规则.md)、[启动说明](../desktop-world/README.md)。
