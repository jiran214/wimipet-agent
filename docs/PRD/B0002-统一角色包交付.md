# B0002 — 统一角色包交付与制作安全

- 日期：2026-11-17（Asia/Shanghai）
- 唯一主责：B / character-studio
- 依据：[B0001](B0001-character-studio.md)、[首轮复盘](../reviews/first-development/README.md)、根 [AGENTS.md](../../AGENTS.md) 的唯一公开契约 `wimipet/1`。
- 已确认范围：用户要求迁移公开包、能力握手与错误/生命周期；保留独立人工体验，不把本模块自测称为全链路验收。
- 生产方：B；消费方：A（实际加载/姿态清单）、C（使用 A 加载后的清单）、D（身份显示）；装配与根规范由协调对话负责，本需求不修改这些模块。

## 目标与验收

1. 只读共同样例可导入、真实 PNG 解码、编辑、确认、导出并回导。包身份、确认版本、人设、头像、动作含义、允许状态、接触类型、优先级及逐帧像素接触点无损保留。
2. 公开边界只使用根规范 `wimipet/1`；旧 `character-studio/0.1` 仅显式导入为未确认创作草稿。未知语义交由创作者填写，不猜测悬挂，不静默移除 root-motion 或非零步幅。
3. 创作草稿可继续保留更大素材、非整数帧时长或位移能力；运行配置明确拒绝，不更新确认快照。导出仅包含已确认且被动作/头像引用的 PNG，不带参考草稿、密钥或任务状态。
4. 按根规范的 512×512、2MiB、256 资源、32MiB UTF-8、动作/帧上限和 Unicode 码点人设上限校验。CRC 正确但压缩内容、滤波或扫描线损坏也必须拒绝。
5. 播放不覆盖正在编辑的帧时长与接触点；应用后保留所选帧。取消、超时、草稿变更、切换/重置和退出后的迟到结果不能变成新候选或覆盖确认版本。
6. 提供模块能力声明、必需能力核对、结构化错误及带会话/请求 ID/截止时间的生命周期适配；重复请求不重复执行，有效去重记录不因容量不足被提前逐出。
7. 用公开核心真实导出固定文件，供 A 后续加载；明确区分 B 协议验证、浏览器操作、真实消费者验证及模型效果验证。
