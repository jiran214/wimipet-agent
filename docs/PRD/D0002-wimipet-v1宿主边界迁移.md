# D0002 — wimipet/1 宿主边界迁移

- 主责：D / companion-ui；日期：2026-11-17。
- 状态：已实现 D 公开 facade、协议子集校验及模拟消费检查；真实 A/C/装配联调待完成。
- 依据：[根统一契约](../../AGENTS.md)、[首轮复盘](../reviews/first-development/README.md)。保留 [D0001](D0001-companion-ui.md) 的界面目标与边界。
- 生产方：C 的获准消息与回执、B 的角色身份/资产、A 的位置与实际观察策略；D 是展示消费者和用户意图生产方。装配负责人由协调对话负责选择宿主、资源桥与传输实现，D 不修改装配层。

## 已确认的迁移目标

1. 正式入口遵循唯一 `wimipet/1`，能力握手检查必需能力与限制，未知主版本/必需能力显式拒绝。历史 D 草案不再作为新集成标准。
2. 只订阅 C 的用户获准视图；按 seq 保序，保留 messageId、atMs、speaker、audience 与 instanceId。气泡与面板共享同一只读投影，不写第二份消息权威源。
3. 用户输入使用公共请求信封与 InputReceipt；受理前不清空草稿。最多 4000 Unicode 码点、一张 PNG/JPEG、2MiB，图片无正文合法，多图必须明确整批拒绝而非丢弃。限制还受能力交集约束。
4. 资源桥提供 contentRef 与独立 previewUrl，模型输入不携带浏览器 blob URL/File。草稿、在途、已提交和会话释放分别处理。
5. 设置提交具体 ObservationPolicy，包括 policyRevision、paused、scope、cooldownMs、excludedRegions；界面只以宿主上游确认快照表示实际生效，不把请求受理当作 A 应用成功。
6. 请求有截止时间和取消路径，展示结构化错误。新会话、重置和退出隔离迟到结果，解除订阅、计时器、准备任务与资源引用。
7. 正式位置由宿主从物理坐标映射到舞台 CSS 像素，D 不计算物理运动，不将网页舞台称为原生桌面气泡。

## 已实现与验证

- 模块版本 0.2.0；公开入口 `modules/companion-ui/src/index.js`，包含 createCompanionHost、mountCompanion、声明、结构化错误和角色摘要消费者。
- 自带共同样例原样副本，测试校验与只读共享原件 SHA-256 一致；真实 D 代码消费其身份/头像，建立同包双实例。演示的消息/设置/位置仍来自明确标注的模拟提供方。
- 16 项 Node 自动检查通过；使用可控时钟与 microtask 排空，覆盖拒绝、取消、过期、超时、迟到成功及资源释放。
- 临时端口 13724 实际启动；Chromium 1440×1080、390×844 操作检查通过，包括头像解码、图片无正文、多图拒绝、取消/超时保留、设置确认/失败、反馈导出。最终记录以 [使用与验收](../companion-ui/使用与验收.md) 为准。
- 开发代理检查了桌面与窄屏截图；真人主观打扰程度未评审。

## 未决依赖与暂缓项

- C 的真实 getView/subscribe 与请求回执接入、A 实际策略确认、A 物理位置映射、装配资源桥/取消转发/退出顺序仍需真实消费者测试。D 自测不代表四模块全链路通过。
- B/A 的共同包真实导出与完整加载不属于 D 验证；D 不用摘要消费替代资产/动作校验。
- 透明原生窗口、截图排除登记、穿透、焦点、多屏/DPI 未接通；网页截图不作为这些能力的验证。
