# companion-ui 模块协作规则

## 人工体验入口：界面体验台

- 使用多个角色占位图、假位置与预设消息提供独立界面，无需真实 AI、原生桌面或其他业务模块。
- 提供播放、暂停、调速、回放和恢复初始场景的操作，便于反复比较界面改动。
- 样例覆盖多角色交替及密集发言、长消息、屏幕边缘、角色位置变化、角色移除和错误状态。
- 用户可打开面板回看再返回气泡，输入文字、拖入图片、切换接收对象、暂停观察及提交故事事件；用可见的回调反馈确认请求内容。
- 明确标注模拟消息和模拟设置结果，不能以本地按钮变化声称真实观察已经暂停。
- 人工检查阅读清晰度、发言者辨识、遮挡与打扰程度、历史回看、输入便利及两种呈现切换的一致性。
- 保存场景和必要反馈供复现；气泡跟随真实桌宠、原生窗口层级与跨窗口效果还需装配验证，独立演示不能替代。

本目录负责用户操作与对话界面。遵循根目录 `AGENTS.md` 和 [D0001 首版需求](../../docs/PRD/D0001-companion-ui.md)。

## 模块目标与效果评价

- 让用户自然地参与多个角色的日常交流和共同故事，兼顾桌面陪伴感与完整阅读体验。
- 用桌面气泡表达轻量交流，用可展开面板承载深入对话，始终共享同一消息来源，不要求角色聚拢。
- 以用户能辨认发言者、回看错过消息、明确选择接收对象、分享图片和发起事件作为效果评价。
- 以不调用真实模型也能完成界面演示、多个角色不产生混乱或记录分叉作为独立性评价。

## 需求编号与聚焦规则

- 本模块使用独立的 D 编号序列，首份为 `D0001-companion-ui.md`；后续按 D 序列递增，不跟随 A/B/C 编号。
- 每份 D 需求只聚焦用户界面、展示状态及输入输出体验。跨模块改动拆为各模块关联需求，不将对话决策、身体规则或资产制作写入 D 的实现职责。
- 更新目标和需求时同步本文件，保留已确认与待定事项的区别。

## 当前阶段

已有模块内原生 JavaScript 核心界面、Node.js 独立体验台与无密钥测试。运行 `npm start --prefix modules/companion-ui`，测试 `npm test --prefix modules/companion-ui`；详见 [使用与验收](../../docs/companion-ui/使用与验收.md) 和 [接口草案](../../docs/companion-ui/接口草案.md)。该选型仅用于 D 当前实现，不锁定其他模块或正式宿主。真实 A/B/C、原生窗口与模型效果尚未联调验证。

## 职责

- 呈现角色列表、漫画气泡、可展开对话面板、头像、消息与处理状态。
- 接收文字、图片拖入、指定角色或全体发言及故事事件操作。
- 提供观察暂停、设置及打开角色制作工具的入口。
- 根据角色位置定位气泡，支持气泡和面板共享同一对话的呈现切换。

## 边界

- 不调用 AI，不实现消息可见性权限判定、身体规则或序列帧播放器。
- 不维护第二份权威聊天记录，不直接修改其他模块状态；所有操作通过回调或接口提交。
- 不重新实现角色制作工作流，只负责打开或嵌入制作入口。
- 原生窗口与跨窗口坐标适配通过宿主接口注入，不直接依赖 desktop-world 内部代码。

## 接口与状态归属

输入：获准展示的消息视图、角色摘要、角色位置、处理状态和设置视图。
输出：用户消息、分享请求、故事事件、设置变更意图和制作入口请求。
唯一拥有：面板开合、输入草稿、滚动、气泡布局等展示状态。
气泡与面板消费同一消息来源；完整 List 的访问范围由 interaction 决定。

- 不导入其他业务模块实现，不读取其私有目录、数据库或可变状态。
- 对外只暴露明确的公开接口和数据；依赖通过装配层注入，独立运行时使用本地替身。
- 公开协议变更需同步更新对应 D 需求、关联模块需求与相关样例，并说明兼容性；避免泄露框架对象或原生句柄。
- 具体字段与方法签名在实现前单独约定，本文件只确定语义边界。

## 独立运行与测试要求

- 使用假角色、位置、消息流和操作回调独立运行界面，不依赖真实模型或原生桌面。
- 验证多个角色的气泡排布、消息顺序、面板回看、指定对象、图片输入和观察暂停操作。
- 验证面板与气泡避免重复呈现同一句话，切换时不生成新会话或丢失历史。
- 覆盖长消息、角色移除、越界位置、输入失败及空状态；具体视觉方案另行设计。

## 后续实现组织

- 按需建立 `src/`、`demo/`、`tests/`、`fixtures/`；当前不创建空实现或占位测试。
- 实现后记录确切的安装、演示、测试命令和环境前提；演示与产品必须使用相同的核心实现。
- 提供清晰的启动、停止与资源清理方式；后台任务、订阅、文件资源应可释放。
- 自动测试默认不使用真实账号、个人桌面截图或外部模型；真实集成验证显式启用。
