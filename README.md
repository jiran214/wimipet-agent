# Wimipet

留一处，给日常。让几个有不同性格的小伙伴陪你聊天、回应你分享的图片，一起续写故事。

这是 **v0.1.0 首个体验版**。目前大家住在浏览器中的陪伴舞台里；真正趴在桌面窗口上、观察你正在做什么，是接下来的整合目标。

## 开始体验

目前需要 Windows、Python 3.11 或更新版本，以及 Node.js 22 或更新版本。首次使用，在项目文件夹打开终端运行一次：

```powershell
python -m pip install -r requirements.txt
```

如果电脑使用 uv 管理 Python，也可以运行 `uv pip install --python python -r requirements.txt`。

之后双击 **start-offline.cmd**，浏览器会自动打开。这个入口不用密钥，使用固定回复，适合先了解操作；它不会真正理解文字或图片。请保留启动窗口，退出时点击页面的“退出陪伴”，或在启动窗口按 Ctrl+C。重新启动即可恢复初始场景；刷新网页不会清空聊天。

## 和伙伴们相处

- 开场会有三位伙伴。你可以对全体说话，也可以在“发送给”里选择其中一位私聊。
- 分享一张 PNG 或 JPEG 图片，也可以只发图、不写文字；每张不超过 2MiB；PNG 单边最多 8192 像素、总像素不超过 1600 万左右。
- 把参与方式切换到“故事事件 / 条件”，为大家安排一个新的故事开场。
- 点击“让大家聊三轮”，观察它们接话；随时点击“停止接话”。
- 简短回复出现在气泡里；点“展开对话”回看完整内容，两种显示方式属于同一段对话。
- 点击“角色制作”，修改角色名字、人设和动作。确认并导出角色包后，回到陪伴页选择“添加角色包”，新伙伴就能加入。可以添加多个角色；加入新伙伴会取消正在生成的旧回复，请等大家说完或重新发送。

## 开启真实 AI 对话

项目里的 `.env.default` 是默认设置。用文本编辑器新建或修改本地 `.env`，只填写希望覆盖的项：

```dotenv
OPENAI_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
OPENAI_API_KEY=在这里填写自己的密钥
OPENAI_MODEL=mimo-v2.6-pro
```

保存后双击 **start.cmd**。真实模式会把当前角色可见的聊天及你主动分享的图片发送给配置的模型服务。密钥仅保存在本地，不进入 Git 提交；环境变量优先于 `.env`，`.env` 优先于 `.env.default`。修改后需重新启动。

本次提供的服务配置实测返回 **401（认证失败）**。因此真实服务的对话效果尚未验收；需要有效且有对应权限的密钥。离线模式仍可体验完整操作流程。真实模型失败会显示处理失败，不会偷偷切换成固定回复。

## 这一版的范围

已连接角色包加载、多角色对话、图片传递、故事事件、动作执行反馈和气泡/面板显示。序列帧由身体模块播放；角色制作台目前提供素材导入和样例生成，尚未接入真实生图服务。

舞台目前不采集桌面，也没有原生透明聊天气泡；观察默认暂停，恢复观察会明确提示尚不支持。想单独体验原生桌宠的拖动、依附，可运行 `python modules/desktop-world/run.py`，它暂时独立于聊天舞台。

聊天和本次添加的角色只在当前运行期间保留。角色制作完成后请导出文件保存。当前没有安装包、长期记忆或自动更新。

如果页面打不开，请先查看启动窗口是否提示端口占用；可在 `.env` 修改 `APP_PORT=8760` 和 `STUDIO_PORT=4312` 后重启。反馈问题时，告诉我们使用的是离线还是真实模式、做了哪些操作、期望看到什么即可，请不要附上密钥。
